# 上游贡献流程

协助开发者向 OpenHarmony 上游提交改动，维护目标分支、对应 Issue、签名提交和 PR 的一致性，并保护原有暂存内容。

位置：`skills/common/cicd/ohos-ci-git-upstream-contribution/`。按组织规范，治理作者为 `openharmony`；原作者 `kingqaquu` 与源仓版本保存在 SKILL.md 元数据中。

## 使用

请使用 ohos-ci-git-upstream-contribution，为当前改动准备向 OpenHarmony 上游提交的方案，保留其它任务的暂存内容。

提供待处理文档、补丁或仓库目标，以及适用的项目规范和 SDK 版本。技能按实际条件输出结果与未验证项，不承诺缺少环境时已完成编译或设备验证。

## 评估

见 [评估步骤](evals/README.md)、[最终报告](evals/report.md) 和 [release 适配记录](evals/release-packaging.json)。原始模型会话、匿名判分、首轮问题和后续修订证据保留在 evals/results/。部分技能的本组核心通过数与基线持平，具体结论以报告为准，尚待维护者审核。
