# ohos-dev-hdc-reverse-ssh-setup

Common OpenHarmony HDC transport skill for reaching a Windows USB-connected device from Linux through a loopback reverse SSH tunnel.

Generic HDC target-state diagnosis, device selection, service recovery, and mutation safety rules come from `ohos-dev-hdc-command-usage`. This skill adds only the Linux-to-Windows transport and Windows-side HDC reachability proof.
