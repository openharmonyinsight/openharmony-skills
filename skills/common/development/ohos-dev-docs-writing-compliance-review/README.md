检查 OpenHarmony 文档的结构、术语、内容元素和示例代码风格，结合项目约定区分确定缺陷、风格建议与未验证项。

位置：`skills/common/development/ohos-dev-docs-writing-compliance-review/`。按组织规范，治理作者为 `openharmony`；原作者 `kingqaquu` 与源仓版本保存在 SKILL.md 元数据中。

## 使用

请使用 ohos-dev-docs-writing-compliance-review 检查 guide.md 的写作合规，采用当前仓库文档规范。

提供待处理文档、补丁或仓库目标，以及适用的项目规范和 SDK 版本。技能按实际条件输出结果与未验证项，不承诺缺少环境时已完成编译或设备验证。
