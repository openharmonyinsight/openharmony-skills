# 内容展示与文档仓布局增量（源4.x、10.x的保留项）

只读取当前任务实际出现的元素。以下是迁入的默认约定，不能替代目标仓的模板与版本约定。

| 规则 | 检视决策 |
|---|---|
| 4.1 列表 / 4.2 表格 | 默认列表“- ”、层级≤2，表格建议≤9行、≤4列；先核对渲染效果和查阅需要，长参数表不因超阈值直接判不可用。缺省值、无、不涉及含义不同，不能统一替换。 |
| 4.3 图片 | 默认本地语义化图片路径；无版权依据只能标未验证。截图比较文字、组件与布局需实际可读图片，非 UI 示例不要求效果图，不强制所有截图1920×1080。 |
| 4.7 单位 | 参数单位和取值边界优先核对 SDK/规格；排版单位风格不能覆盖真实参数字符串。 |
| 4.8 标点 / 4.9 转义 | 检查渲染后的表达，不机械给已有代码块/行内代码再转义；项目允许的 `<sup>` 版本角标不作为非法 HTML。 |
| 10.x 文档仓布局 | 依据当前文档仓的贡献规范、目录说明或既有同类文档，核对普通指南、API参考、图片资源和README所在目录；不能以应用工程resources/entry/ets结构替代文档仓布局。不得硬套源仓的reference/apis或图片目录名；缺少项目布局依据时标未验证。新增/重命名文档还需加载结构与术语的2.5检查入站导航；布局与导航是两个判据，同一根因的缺陷合并计数。 |
| 4.10 路径 | 区分设备路径、主机路径与项目相对路径；命令中的空格路径需要正确引用。项目相对路径不应强制补成本机绝对路径。 |

证据边界示例（不是本地4.5规则）：相对链接 `../apis/foo.md#bar` 无本地目标可核对→未验证；给定目标渲染锚点列表不含bar→可向来源链接检查提供证据，由来源技能按实际执行的规则ID记录结论。本例不声称已运行来源检查，亦不计入本地条目覆盖；网络不可用本身不是断链证据。

常规链接、术语、隐私、完整性、交付版本及应用工程目录结构检查按 SKILL.md 委派；普通文档导航同步与文档仓布局分别由本地2.5、10.x保留。网络不可用不等于断链；本地缺目标不能假装验证通过。
