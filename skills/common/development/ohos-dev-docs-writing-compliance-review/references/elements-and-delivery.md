# 内容展示增量（源4.x的保留项）

只读取当前任务实际出现的元素。以下是迁入的默认约定，不能替代目标仓的模板与版本约定。

| 规则 | 检视决策 |
|---|---|
| 4.1 列表 / 4.2 表格 | 默认列表“- ”、层级≤2，表格建议≤9行、≤4列；先核对渲染效果和查阅需要，长参数表不因超阈值直接判不可用。缺省值、无、不涉及含义不同，不能统一替换。 |
| 4.3 图片 | 默认本地语义化图片路径；无版权依据只能标未验证。截图比较文字、组件与布局需实际可读图片，非 UI 示例不要求效果图，不强制所有截图1920×1080。 |
| 4.7 单位 | 参数单位和取值边界优先核对 SDK/规格；排版单位风格不能覆盖真实参数字符串。 |
| 4.8 标点 / 4.9 转义 | 检查渲染后的表达，不机械给已有代码块/行内代码再转义；项目允许的 `<sup>` 版本角标不作为非法 HTML。 |
| 4.10 路径 | 区分设备路径、主机路径与项目相对路径；命令中的空格路径需要正确引用。项目相对路径不应强制补成本机绝对路径。 |

示例：相对链接 `../apis/foo.md#bar` 无本地目标可核对→未验证；目标文件存在但给定渲染锚点列表没有 bar→4.5 可确认问题。前者不能报告成确定断链。

常规链接、术语、隐私、完整性、交付版本及目录结构检查按 SKILL.md 委派。网络不可用不等于断链；本地缺目标不能假装验证通过。
