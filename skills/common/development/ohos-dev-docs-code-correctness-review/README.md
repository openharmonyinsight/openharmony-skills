# 文档代码正确性检视

对照匹配版本声明和配置规范检视 OpenHarmony 文档示例，区分代码、版本和图文一致性的已验证结果与条件缺口。

位置：`skills/common/development/ohos-dev-docs-code-correctness-review/`。按组织规范，治理作者为 `openharmony`；原作者 `kingqaquu` 与源仓版本保存在 SKILL.md 元数据中。

## 使用

请使用 ohos-dev-docs-code-correctness-review 核对文档中的代码与配置示例，SDK 不可用的项目标记未验证。

提供待处理文档、补丁或仓库目标，以及适用的项目规范和 SDK 版本。技能按实际条件输出结果与未验证项，不承诺缺少环境时已完成编译或设备验证。
