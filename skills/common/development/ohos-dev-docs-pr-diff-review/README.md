# 文档 PR 改动检视

针对 OpenHarmony 文档 PR 的新增、修改和关键删除内容进行检视，提供精确定位、规则依据及未覆盖范围说明。

位置：`skills/common/development/ohos-dev-docs-pr-diff-review/`。按组织规范，治理作者为 `openharmony`；原作者 `kingqaquu` 与源仓版本保存在 SKILL.md 元数据中。

## 使用

请使用 ohos-dev-docs-pr-diff-review 检视这份文档 PR 补丁，只报告本次改动引入的问题。

提供待处理文档、补丁或仓库目标，以及适用的项目规范和 SDK 版本。技能按实际条件输出结果与未验证项，不承诺缺少环境时已完成编译或设备验证。

## 评估

见 [评估步骤](evals/README.md)、[最终报告](evals/report.md) 和 [release 适配记录](evals/release-packaging.json)。原始模型会话、匿名判分、首轮问题和后续修订证据保留在 evals/results/。部分技能的本组核心通过数与基线持平，具体结论以报告为准，尚待维护者审核。
