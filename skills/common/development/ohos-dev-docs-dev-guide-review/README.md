# 开发指南检视

沿 OpenHarmony 开发任务链检查指南的工程依赖、权限、调用前提与结果验证，识别会阻断用户操作的内容缺口。

位置：`skills/common/development/ohos-dev-docs-dev-guide-review/`。按组织规范，治理作者为 `openharmony`；原作者 `kingqaquu` 与源仓版本保存在 SKILL.md 元数据中。

## 使用

请使用 ohos-dev-docs-dev-guide-review 检查开发指南中的前置条件和操作断点，只检查必选项。

提供待处理文档、补丁或仓库目标，以及适用的项目规范和 SDK 版本。技能按实际条件输出结果与未验证项，不承诺缺少环境时已完成编译或设备验证。
