# proposal-check-matrix

proposal-check 的审查判据，按"总览+明细表"组织。待SE澄清与TSE复核列均留空，由人工审核填写。

## 前言（判据阅读约定）

- **通则：** PASS=存在/完整/清晰/明确/无歧义；FAIL=不存在/缺失/模糊/有歧义；WARN=AI无法判定，标疑由人工二次判定
- **静默缺失：** 未显式标注"不涉及"的空白项，按 FAIL 判据处理
- **待SE：** TSE对SE澄清回应的复核
- **工作流规则：** 结构缺失先FAIL不细判；显式不涉及按 PASS 处理；FAIL/WARN 由主 agent 回修或标注待人工处理

## 术语速查

| 术语 | 一句话定义 | 判据角色 |
|---|---|---|
| feature.md | 原始诉求源 | 检查域一溯源比对基准 |
