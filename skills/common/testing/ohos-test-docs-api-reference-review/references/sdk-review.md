# SDK 证据、语言分支与40维度

证据绑定元组：文档提交/版本 + SDK版本/路径 + 应用模型 + 声明对象。只拥有更新 SDK 时，不可用“新增重载没出现在旧文档”判旧文档遗漏。

| 发现的证据 | 能支持 | 不能直接支持 |
|---|---|---|
| 匹配 SDK 声明、头文件及 JSDoc | 名称/签名/可选性/since/权限/syscap/继承等已给字段 | 运行时默认值、设备行为、错误恢复实效 |
| 匹配实现和可复现结果 | 指定环境下的行为和异常路径 | 未覆盖设备、其它版本、所有错误码均正确 |
| IDE 自动补全、网络摘要、不同版 SDK | 查找线索 | 作为当前版本错误的最终依据 |

## 对应语言分支

- ArkTS/JS：逐对象比对模块路径、导出/继承范围、重载、参数可选性、同步/Promise/callback 返回方式，再核对since/权限/syscap等已给元数据；模块起始版本不能无条件套给后续新增成员。示例闭包 this 要按回调契约，不能以箭头形式判断一切正确。
- C：先确认头文件版本，再比对返回类型、参数顺序、指针层级、const位置、结构体/宏/错误码。文档的相同英文名不能代替相同 C 类型；所有权和可空性未给说明时标契约缺口，不能从 const 推导必定无副作用。
- 两者共通：缺声明只能检查内部自相矛盾；声明与样例一致只能判该字段满足，不给整篇“SDK验证通过”。

## 40个验证维度索引

仅用于定位适用项，通用编辑知识不再展开为教程。每项以字段/证据判定，未给必要证据记未验证。

1. 模块功能/场景（11.x）：是否有使用对象及能力范围。
2. 模块设计逻辑（11.x）：复杂依赖是否能沿关联入口解释。
3. 接口含义/场景/效果（12.x）：可观察结果是否区分相似接口。
4. 使用建议/前提（12.x、RULE-04）：见使用契约，不重复计问题。
5. 废弃替代（12.x）：废弃版本与实际可用替代是否同时明确。
6. 参数含义/场景/效果（12.x）：缺省与显式传值能否区分。
7. 参数使用约束（12.x）：范围/单位/默认/生效/配合关系有证据。
8. 返回值说明（12.x）：类型相同还须有枚举值与结果用途。
9. 错误码完整性（12.x）：接口与汇总表双向对照。
10. 对象集合与 SDK 一致（13.x）：模块/类/方法/常量/枚举不混版本。
11. 字段与 SDK 一致（13.x）：签名/权限/能力/起始版本/继承等逐字段。
12. 功能与实现一致（14.x）：仅已验证环境支持结论。
13. 原理/概念一致（14.x）：文内冲突与实现冲突分开证据。
14. 参数语义正确（15.x）：调用路径而非仅变量名。
15. 单位/范围正确（15.x）：含上下界及越界行为。
16. 返回值与场景正确（16.x）：具体值、格式、分支对应。
17. 错误码原因/解决正确（17.x）：处理步骤能针对给定原因。
18. 语言风格（18.x）：项目约定优先，非语法门禁。
19. 通用排版（19.x）：实际渲染可读性优先于机械阈值。
20. 设备描述（20.x）：以能力判断替代无依据型号宣称。
21. 版本写法（20.x）：沿目标仓since/角标模板，废弃版本分开。
22. 低错（21.x）：叙述错字与真实标识符字面值分开。
23. 链接可达（22.x）：实际读取才可宣称在线有效。
24. 链接目标（22.x）：版本/语言/锚点是否正确。
25. 类型链接（22.x）：自定义类型能否定位，不在代码签名中硬加链接。
26. 示例可用（23.x）：片段/完整工程及验证条件分开。
27. 示例废弃项（24.x）：迁移对照示例可明确保留旧调用。
28. 示例冗余（24.x）：宿主变量可能在截取范围外使用，不推断全工程未用。
29. 参数来源（24.x）：资源、路径、句柄需交代取得方式。
30. 异常处理（24.x）：API片段按模板，完整指南按失败路径。
31. 异步结果（24.x）：消费必须在成功取得之后，不能以异步函数外的变量声明替代。
32. 注释（25.x）：重点解释约束/来源，不要求复述每行代码。
33. 代码风格（25.x）：风格偏好不升为编译错误。
34. 英文资料代码语言（25.x）：中文处理场景与非必要中文注释分开。
35. 省略标记（25.x）：省略需能识别为非执行占位。
36. 命名（25.x）：SDK真实名称不因通用命名偏好改写。
37. 回调（25.x）：依赖词法this才优先箭头，保留契约要求的动态this。
38. 术语（26.x）：无目标术语表不推断官方用词。
39. 原理图表（26.x）：是否确有复杂状态/依赖解释需求。
40. 步骤语言（27.x）：条件、操作主体及结果能否对应。

示例：文档open返回string，而匹配SDK返回number→13.x确定缺陷；SDK未写flags默认值→不能填0，只能记录默认契约未验证/文档缺失。全篇已有deprecated解释但片段没重复，不能仅看片段判未提供替代。
