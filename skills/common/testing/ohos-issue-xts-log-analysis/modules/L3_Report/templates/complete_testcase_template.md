## 使用说明

### AI操作流程

1. **提取基本信息**：从module_run.log提取用例名、testsuite、执行序号、消耗时间
2. **提取时间窗**：从hilog [Hypium]标记提取起始/结束时间，用grep -n提取行号
3. **生成证据链**：
   - 查询API对应的domain：`python3 map_domain.py [API/模块名]`
   - 填充表格：API | 子系统 | domain | 日志行 | 时间
   - 绘制追溯图：源码→@ohos模块→子系统→domain→日志过滤
4. **摘录关键日志**：从hilog切片中摘录带行号的关键失败日志
5. **定位源码**：从源码目录定位测试文件，提取关键代码片段
6. **定界问题**：根据证据链和日志分析，填写问题定界表格

### 同根因判定标准

**判定为同根因**：
- 相同的失败原因（如：同一组件的相同属性问题）
- 相同的错误类型（如：都是"组件未找到"）
- 相同的API调用链路

**判定为独立根因**：
- 不同的组件或模块
- 不同的错误类型
- 不同的API调用

### 格式检查清单

生成每个用例后，检查：
- [ ] 基本信息：包含"所在日志（hilog）"
- [ ] 时间窗提取：包含"起始行号"、"结束行号"
- [ ] 源码→领域证据链：独立成节，包含表格+追溯图
- [ ] 关键日志片段：带行号摘录
- [ ] 源码定位与分析：包含源码位置、片段、分析
- [ ] 问题定界：独立表格
