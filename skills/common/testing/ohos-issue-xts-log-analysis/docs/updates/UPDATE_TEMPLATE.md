# Skill更新日志模板

> 标准化更新日志格式，便于追溯改进历史

---

## 更新日志格式

**文件命名**: `UPDATE_YYYYMMDD.md`

**必须包含章节**:
1. 更新原因
2. 更新内容
3. 更新效果
4. 验证方法

---

## 模板内容

```markdown
# Skill更新日志 - YYYYMMDD

## 更新原因

**问题场景**: 描述触发更新的具体场景

**根因分析**: 分析问题的根本原因

---

## 更新内容

### 1. SKILL.md更新（如有）

- 更新位置：第X-Y行
- 更新内容：具体内容

### 2. 脚本更新（如有）

- 脚本名称：xxx.py
- 更新内容：具体改进

### 3. 数据更新（如有）

- 数据文件：xxx.json
- 更新内容：具体补充

### 4. 文档更新（如有）

- 文档名称：xxx.md
- 更新内容：具体补充

---

## 更新效果

### 更新前的问题

1. 具体问题描述
2. 具体问题描述

### 更新后的改进

1. ✅ 改进点1（效果评估）
2. ✅ 改进点2（效果评估）

---

## 验证方法

下次使用时，应满足以下条件：

1. 验证条件1（验证方式）
2. 验证条件2（验证方式）

---

**更新时间**: YYYY-MM-DD  
**更新人员**: 维护者姓名  
**验证状态**: 待验证/已验证  
**改进优先级**: P0/P1/P2
```

---

## 使用说明

1. **每次改进**：创建新的UPDATE_YYYYMMDD.md文件
2. **命名规则**：使用改进日期命名（如UPDATE_20260706.md）
3. **存储位置**：docs/updates/目录
4. **内容要求**：必须包含上述4个章节
5. **追溯方式**：通过日期和标题快速定位
