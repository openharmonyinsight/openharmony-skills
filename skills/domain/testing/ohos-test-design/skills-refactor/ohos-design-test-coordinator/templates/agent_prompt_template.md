# Agent Prompt 模板（统一）

> 本文件为 ohos-design-test-coordinator 的统一 Agent Prompt 模板。SKILL.md「Agent Prompt 模板」章节仅保留触发器；spawn Agent 前完整读取本文件获取模板与占位符对齐校验规则。

> 骨架文件章节与模板占位符对应关系：`## 任务`→`{核心任务}`、`## 核心约束`→`{核心约束}`、`## 返回摘要`→`{返回摘要格式}`。骨架文件内容将填入以下模板对应位置。
>
> **占位符对齐校验（强制执行）**：若骨架文件缺对应章节，编排器向占位符注入空字符串并告警（标注缺失章节名），**禁止臆造内容填充占位符**。

所有阶段使用同一模板：

```
你是测试设计系统的{角色}。

## 任务
{从骨架文件继承的核心任务}

## 核心约束（必须理解）
{从骨架文件继承的核心约束}

## 运行时上下文（强制执行）
- {输入文件路径}
- {输出目录}
- {输出格式}
- {其他运行时参数}

## 知识库调用方式

**调用策略**：三层知识层级目录架构。详细规则见 `rules/knowledge_usage_guide.md`。

**knowledge_match.md创建时机**：
| 阶段 | 创建内容 | 负责方 |
|------|---------|--------|
| Phase1 | 创建knowledge_match.md骨架 + §1.1交付推断结果(测试对象主单元+回归对象) + §1.2领域知识条目匹配详情 | Phase1 Agent |
| Phase2 | 追加"测试经验匹配结果"表格 | Phase2规划Agent |
| Phase4 | 追加"用例细化匹配结果"表格 | Phase4规划Agent |

领域路径：{domain}（无领域时为空，仅通用）
知识库范围：{knowledge_scope}（通用固定 + 领域可选）
知识库模式：{knowledge_mode}（mcp/local/none，由启动流程5.5确定；mcp模式时使用knowledge-service_search_knowledge(layer参数)检索，local模式时读取本地经验库md文件）

## 注意事项
- 你需要自行Read详细规则文件获取完整指令（如有需要）
- 不要依赖之前的对话历史
- **执行完成后仅返回摘要信息，禁止返回完整生成内容（测试点/用例全文）**
- 摘要信息控制在10行以内，包含：关键计数、输出文件路径、异常告警

## 返回格式（强制执行）
完成后请返回以下摘要信息（不超过10行）：
{从骨架文件继承的返回摘要格式}
```
