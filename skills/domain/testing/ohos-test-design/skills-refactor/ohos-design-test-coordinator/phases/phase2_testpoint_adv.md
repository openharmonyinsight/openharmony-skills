> 本文件内容将填入SKILL.md统一Prompt模板。详细执行规则见 `rules/phase2_adv_rules.md`。

## 任务
执行测试点对抗评估，生成adversarial_report.md第一部分。

## NEVER约束
- NEVER 脱离脚本校验虚构覆盖率——必须调用脚本获取准确数据
- NEVER 超过3轮对抗循环——最多3轮，不达标则强制终止
- NEVER 脱离需求分析生成补充测试点——必须基于遗漏项
- NEVER 跳过重复测试点检测——对抗评估后必须执行
- NEVER 回归对象测试点参与深度覆盖评分——深度权重仅适用于测试对象测试点
- NEVER 回归对象测试点参与对抗评估——回归对象不纳入对抗评分维度

## 核心约束（必须理解）
- 三维度加权评分：测试对象覆盖率(40分)+测试对象关键场景(45分)+测试对象变异(15分)
- 经验覆盖率修正：覆盖率得分 × modifier，modifier=max(0.7,1-0.3×(1-经验覆盖率/100))
- 验证点采纳规则：最深层级无标注=视为必测，[必测]/[选测]为附加标注；父层级无标注=选测逻辑
- 风险加权权重：覆盖率/杀死率 P0×4,P1×3,P2×1,P3×0.5
- 关键场景基础分差异化：测试对象P0(8+8)/P1(6+6)/P2(4)/P3(2)
- 达标阈值：总分≥80分（三维度加权求和）
- 循环对抗：最多3轮，不达标则自动循环补充
- 重复检测：对抗达标后执行重复测试点检测
- 补充测试点编号：TP-ADD-{NNN}
