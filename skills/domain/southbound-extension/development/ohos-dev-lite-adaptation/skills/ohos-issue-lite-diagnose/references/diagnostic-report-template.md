# 诊断报告模板

> 诊断报告输出模板。按本结构填写一次「假设→验证→结论」闭环的结果。
> 案例格式参考 `diagnostic-cases.md`；诊断纪律见 SKILL.md（Step 2.3 版本标记核对 / Step 2.4 良性报错判据 / Step 2.5 先联网搜再验证）。
> **核心纪律**：根因在实测确认前一律标「假设/待验证」，不得直接写「确认根因」（见 P-显式未验证）。
