# ArkUI

ArkUI 框架相关技能，涵盖 UI 组件、布局、动画、事件处理等。

## Development

| Skill | Description |
| --- | --- |
| `ohos-dev-arkui-ace-engine-build` | ACE Engine 编译、测试、SDK 构建和快速编译判断。 |
| `ohos-dev-arkui-build-error-analyzer` | ACE Engine 构建错误提取、分类和修复建议。 |
| `ohos-dev-arkui-code-review` | ArkUI ACE Engine 代码质量、架构、稳定性和安全检视。 |
| `ohos-dev-arkui-compile-analysis` | ACE Engine 单文件编译耗时、峰值内存和头文件依赖分析。 |
| `ohos-dev-arkui-hdc-demo-device-self-verify` | 通过 HDC 推送 HAP 或 native 产物到设备并采集端到端自验证证据。 |
| `ohos-dev-arkui-header-optimization` | ArkUI 头文件依赖优化和 include 收敛。 |
| `ohos-dev-arkui-host-tdd` | ACE Engine Host 单元测试的合规审计、防御性 TDD、构建委托、精确执行与证据报告。 |
| `ohos-dev-arkuix-framework-api-adapter` | ArkUIX Framework API 适配分析和实现指导。 |
