`_path.txt` 与 `MISSING` 的关系是：

- `build/test.gni` 无条件写入 `<target>_path.txt`；`_has_sources` 只控制 `.sources` 文件的写入。
- marker 内容 `//foundation/arkui/ace_engine/test/unittest/core/pattern/text` 是 target 的 GN 源目录，不是可执行文件路径。
- `run_host.py` 将 `_path.txt` marker 与实际可执行文件合并做发现：只有同名可执行文件存在时才算 compiled/`OK`；只有 marker、没有可执行文件时就显示 `MISSING`。
- captured inventory 正是这种情况：marker 存在，但 stripped 与 `exe.unstripped` 均不存在，所以显示 `MISSING`。

故 `MISSING` 表示这次文件系统发现中“知道有这个声明，但未找到同名可执行文件”；它本身不等价于编译失败。本 fixture 的静态 GN 图进一步表明，更直接的原因是该 target 没有被接入 Host 依赖闭包。
