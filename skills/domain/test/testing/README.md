# Testing

测试执行阶段相关技能，涵盖 XTS 测试用例生成、编译验证、覆盖率分析等。

测试执行阶段关注：依据设计文档或覆盖率报告生成测试代码、注册测试套、格式与质量验证、编译验证、设备测试执行和覆盖率前后对比。

## Skills

- [ohos-test-arkts-xts-generation](ohos-test-arkts-xts-generation/) — ArkTS XTS 测试用例生成器，解析 .d.ts 生成 Hypium 测试用例，支持 5 种 Flow（A/B/C/D/E）模式、ArkTS-Dyn/Sta 双语法、覆盖率分析与编译验证。
- [ohos-test-capi-xts-generation](ohos-test-capi-xts-generation/) — CAPI XTS 测试用例生成器，解析 .h 头文件生成 N-API 封装与 ArkTS 测试代码，支持三重校验与编译验证。
