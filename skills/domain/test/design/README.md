# Design

测试设计阶段相关技能，涵盖测试用例设计、测试策略制定、测试设计文档生成等。

测试设计阶段关注：依据 API 声明（.d.ts）和需求规格，设计测试用例的结构、覆盖维度（参数/错误码/返回值/边界值/事件）、测试类型分级和控件 ID 契约，产出测试设计文档（`.design.md`）作为后续代码生成的依据。
