# Gherkin 场景库

> Feature Spec 的可选场景参考。先判断适用性，再按需复制到具体 Spec。示例中的阈值和行为须按实际设计调整。

## 使用规则

| 规则 | 说明 |
|------|------|
| 先筛选再展开 | 只展开适用场景 |
| 绑定设计约束 | 全局特性场景回链到 design.md |
| 参数按项目填写 | 时间、比例、阈值等不得直接沿用示例值 |
| 保留可验证性 | Then/And 应能通过测试、日志或报告验证 |
| 不替代专项测试 | 最终验证以 XTS、专项测试和质量门禁为准 |

## 一、全局特性影响

```gherkin
Feature: 全局特性影响 - 无障碍

  Scenario: 屏幕阅读器支持
    Given 用户开启屏幕阅读器
    When 访问本特性的可交互界面
    Then 所有可交互元素应有可理解的无障碍标签
    And 焦点顺序应符合用户操作路径
    And 状态变化应能被无障碍服务感知

  Scenario: 视觉辅助
    Given 用户开启高对比度或视觉辅助能力
    When 使用本特性
    Then 文本和关键图形应保持足够对比度
    And 颜色不应作为唯一信息传递方式
    And 文本缩放后不应截断、重叠或遮挡关键操作

  Scenario: 操作辅助
    Given 用户依赖键盘、开关控制、语音或其他辅助输入
    When 操作本特性
    Then 核心功能应可通过辅助输入完成
    And 触控目标大小和响应时间应满足可访问性要求
```

```gherkin
Feature: 全局特性影响 - 大字体

  Scenario Outline: 动态字体缩放
    Given 系统字体缩放比例为 <缩放比例>
    When 本特性渲染文本内容
    Then 文本应按系统设置缩放
    And 布局应自适应调整
    And 不应出现文本截断、重叠或关键操作不可见

    Examples:
      | 缩放比例 | 预期行为 |
      | 0.85 | 文本缩小且布局稳定 |
      | 1.0 | 默认大小正常显示 |
      | 1.3 | 大字体布局自适应 |
      | 2.0 | 超大字体支持滚动或重排 |

  Scenario: 超大字体下的信息完整性
    Given 系统处于超大字体模式
    When 使用本特性
    Then 所有功能性文本应完整可见或可通过滚动查看
    And 关键操作不应因字体大小而不可点击
```

```gherkin
Feature: 全局特性影响 - 深色模式

  Scenario: 深色模式切换
    Given 系统处于 [浅色/深色] 模式
    When 打开本特性
    Then 界面应跟随系统主题
    And 文本和图标在深色/浅色背景下均应清晰可辨
    And 不应出现硬编码颜色导致的显示异常
```

```gherkin
Feature: 全局特性影响 - 多窗口/分屏

  Scenario: 窗口尺寸变化
    Given 应用处于多窗口或分屏状态
    When 窗口尺寸或方向发生变化
    Then 本特性界面应正确响应窗口变化
    And 不应出现功能失效、崩溃或状态丢失
```

```gherkin
Feature: 全局特性影响 - 多用户

  Scenario: 用户隔离
    Given 系统已创建多个用户
    When 不同用户分别使用本特性
    Then 用户间数据应隔离
    And 用户切换时不应出现数据残留或权限泄漏
```

```gherkin
Feature: 全局特性影响 - 版本升级

  Scenario: 版本升级兼容
    Given 设备从 <旧版本> 升级到 <新版本>
    When 升级完成后使用本特性
    Then 已有数据应正确迁移或兼容
    And 新版本特性功能应正常可用

    Examples:
      | 旧版本 | 新版本 |
      | OH-5.0 | OH-6.0 |
      | OH-6.0 | OH-6.1 |
```

```gherkin
Feature: 全局特性影响 - 生态兼容

  Scenario: 跨设备类型兼容
    Given 设备类型为 <设备类型>
    When 使用本特性
    Then 核心功能应在该设备上正常可用
    And 如有不支持的功能，应有明确的 Capability 声明

    Examples:
      | 设备类型 |
      | 默认设备 |
      | 平板 |
      | 穿戴 |
      | 车机 |
```

## 二、非功能性需求

```gherkin
Feature: 非功能性需求 - 性能与资源

  Scenario: 接口响应性能
    Given 系统处于 [正常负载/高负载] 状态
    When 调用 [接口名称]
    Then P95 响应时间应小于 [阈值]
    And P99 响应时间应小于 [阈值]
    And 性能测试报告应记录测试环境、样本量和基线版本

  Scenario: 内存占用与泄漏
    Given 系统连续运行 [时长]
    When 重复执行 [核心操作] [次数]
    Then 新增内存开销应小于 [阈值]
    And 不应出现持续增长的不可回收内存
    And hidumper 或等效工具应能输出验证证据

  Scenario: 功耗影响
    Given 设备处于 [前台/后台/熄屏] 状态
    When 本特性持续运行 [时长]
    Then 功耗变化应满足 [阈值/基线对比要求]
    And 后台运行不应触发非必要唤醒
```

```gherkin
Feature: 非功能性需求 - 安全与权限

  Scenario: 权限校验
    Given 调用方未获得 [权限名称]
    When 调用 [接口/能力]
    Then 系统应拒绝访问
    And 应返回明确错误码 [错误码]
    And 应记录安全相关日志

  Scenario: 输入校验
    Given 调用方传入 <输入类型>
    When 输入值为 <输入值>
    Then 系统应执行边界校验
    And 对非法输入应返回错误码 <错误码>
    And 不应发生崩溃、越权访问或资源泄漏

    Examples:
      | 输入类型 | 输入值 | 错误码 |
      | 空字符串 | "" | [错误码] |
      | 超长字符串 | [length] | [错误码] |
      | 特殊字符 | [chars] | [取决于设计] |
      | 越界数值 | [value] | [错误码] |
```

```gherkin
Feature: 非功能性需求 - 问题定位

  Scenario: 关键路径可追踪
    Given 特性运行过程中发生错误
    When 错误码为 [错误码]
    Then 错误信息应包含足够上下文
    And 对应日志应包含 [traceId/requestId/调用链标识]
    And 日志级别应适合生产环境

  Scenario: 诊断信息完整
    Given 特性运行中出现异常状态
    When 通过 hilog 或等效工具查询
    Then 应能获取异常发生时的关键状态信息
    And 不应因日志输出导致性能显著劣化
```

```gherkin
Feature: 非功能性需求 - 可靠性与韧性

  Scenario: 异常恢复
    Given 依赖服务 [服务名] 暂时不可用
    When 本特性调用该服务失败
    Then 应有明确的错误码或异常处理
    And 依赖恢复后本特性应能继续正常工作
    And 不应出现状态损坏或死锁

  Scenario: 资源释放
    Given 本特性使用 [文件句柄/数据库连接/网络连接]
    When 操作完成或异常中断
    Then 所有资源应正确释放
    And 不应因资源泄漏导致长期运行后功能退化
```

```gherkin
Feature: 非功能性需求 - 生命周期

  Scenario: 前后台切换
    Given 应用从 [前台→后台→前台]
    When 切换过程涉及本特性
    Then 特性状态应正确保持或恢复
    And 不应出现状态丢失、重复初始化或回调异常

  Scenario: 进程重启
    Given 所在进程重启
    When 重启后首次使用本特性
    Then 持久化数据应完整
    And 特性应正常初始化而不依赖上一次运行的临时状态
```
