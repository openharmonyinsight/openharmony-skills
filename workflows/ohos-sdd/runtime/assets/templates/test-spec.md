## 测试范围

**测试重点：**
- 用户可感知行为
- 公开接口或 SDK 暴露接口的输入输出
- 跨模块、跨进程、跨设备或跨版本交互
- 单元测试无法充分覆盖的系统级约束

**非测试重点：**
- 已由单元测试充分覆盖的局部实现细节
- inner/system/internal/private 接口的内部逻辑
- 不在本次需求范围内的性能、安全或功耗主题
