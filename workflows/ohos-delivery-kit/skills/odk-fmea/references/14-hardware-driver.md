# 硬件与驱动故障模式（Hardware / Driver）

本类覆盖 **CPU、GPU、TP、内存、存储** 等硬件故障，以及 **EC hang、驱动崩溃/丢失/加载延迟、驱动内存泄漏、恶意驱动、设备创建超限** 等驱动层故障（合并自原 14-hardware-fault 与 28-driver-fault）。

---

## 一、硬件故障（Hardware）

## HW-01 CPU 故障

### HW-01a CPU 占用率过高
- 典型原因：应用/服务主线程死循环、高频轮询、大量计算任务未分流；后台进程恶意保活；系统调度异常。
- 典型影响：X 秒后弹出应用 ANR 对话框；系统整体卡顿；其他进程无法获得 CPU 时间片；整机发热降频。
- 故障注入：构造 CPU 密集型循环（如死循环计算）；注入高优先级实时进程抢占 CPU；rphone 工具注入 CPU 高负载。
- 日志/Trace：ANR 检测日志（THREAD_BLOCK_6S）；CPU 使用率统计（/proc/stat、top）；thermal 日志；HiAppEvent 资源事件。
- 消减建议：耗时任务移工作线程/FFRT；后台任务限制 CPU 使用率（cgroups）；ANR 检测后杀应用恢复；CPU 温度监控与降频保护。

### HW-01b CPU 频率波动 / 下线
- 典型原因：电源管理异常、温控策略错误、CPU 核心离线、DVFS 调频失败。
- 典型影响：系统进入 fastboot 或整机重启；性能抖动导致用户体验劣化。
- 故障注入：注入 CPU 频率跳变（高低频快速切换）；模拟 CPU 核心离线；温控阈值异常触发。
- 日志/Trace：kernel cpufreq 日志；watchdog 超时事件；fastboot 进入日志；panic/oops 日志。
- 消减建议：DVFS 策略健壮性校验；CPU 核心离线检测与自动恢复；watchdog 保护；关键路径不依赖特定 CPU 频率。

### HW-01c CPU 绑核异常
- 典型原因：进程/线程 affinity 设置错误，绑定到不存在或已离线的核心；绑核后负载不均。
- 典型影响：业务进程无法调度或性能劣化；关键任务被绑定到低效核心。
- 故障注入：设置非法 affinity mask；绑定到已离线核心；多线程竞争同一核心。
- 日志/Trace：sched_setaffinity 失败日志；任务调度延迟统计；CPU 负载不均日志。
- 消减建议：affinity 设置前校验核心有效性；关键服务不强制绑核或绑定多个核心；调度器负载均衡监控。

### HW-01d CPU 降频（Thermal Throttling）
- 典型原因：高温触发温控降频；散热设计不足；长时间高负载运行。
- 典型影响：系统卡顿、帧率下降、业务响应延迟；用户体验劣化。
- 故障注入：模拟高温环境或注入温控事件；构造持续高负载使温度上升。
- 日志/Trace：thermal zone 温度日志；cpufreq 降频记录；HiSysEvent 温度告警。
- 消减建议：业务层感知降频并降级（降低画质/帧率）；温控策略分级（紧急降频 vs 渐进降频）；散热优化。

## HW-02 GPU 故障

### HW-02a GPU 频繁上下电
- 典型原因：电源管理策略错误、GPU 空闲超时过短、频繁唤醒/休眠；驱动状态机异常。
- 典型影响：界面操作不响应；整机重启；帧率抖动；功耗异常。
- 故障注入：注入 GPU 电源状态快速切换；模拟 GPU 唤醒失败场景。
- 日志/Trace：GPU 电源状态日志；SurfaceFlinger 丢帧统计；watchdog 超时事件。
- 消减建议：GPU 电源状态切换防抖（hysteresis）；关键渲染路径保持 GPU 在线；电源状态异常检测与恢复。

### HW-02b GPU 复位超时（硬复位/软复位/Job Timeout/Fence Timeout）
- 典型原因：GPU 任务死锁、驱动命令队列满、硬件无响应；fence 信号未释放。
- 典型影响：界面不响应、黑屏/花屏；整机重启；桌面无法滑动；只能长按电源键恢复。
- 故障注入：注入 GPU 命令无限循环；构造 fence 永不释放；模拟 GPU 硬件无响应。
- 日志/Trace：GPU 驱动复位日志（`gpu reset`、`fence timeout`）；SurfaceFlinger 冻屏检测；watchdog 事件。
- 消减建议：GPU 任务超时监控（job timeout）；fence 超时检测与 GPU 复位；关键路径降级（CPU 渲染兜底）；watchdog 自动重启。

### HW-02c GPU 内存页错误（GPU Page Fault）
- 典型原因：GPU 访问未映射/已释放内存；地址翻译错误；显存分配失败。
- 典型影响：界面显示花屏；手机黑屏、电源键点不亮；应用崩溃。
- 故障注入：构造 GPU 访问非法地址；释放 GPU 正在使用的内存；显存分配失败注入。
- 日志/Trace：GPU page fault 日志；ION/dma-buf 错误日志；faultlog 崩溃栈。
- 消减建议：GPU 内存映射严格生命周期管理；释放前等待 GPU 空闲；显存分配失败降级路径；GPU 错误处理回调。

### HW-02d GPU 丢帧
- 典型原因：GPU 负载过高、渲染管线阻塞、VSync 丢失；间隔丢帧、相同帧丢失、升序/降序丢帧。
- 典型影响：界面卡顿、动画不流畅；用户体验劣化。
- 故障注入：注入间隔丢帧（固定间隔/随机间隔）；构造相同帧重复/丢失；升序/降序丢帧。
- 日志/Trace：SurfaceFlinger 丢帧统计（`dropped frames`）；GPU 渲染耗时 trace；Choreographer 跳帧日志。
- 消减建议：渲染耗时监控与告警；丢帧检测后动态降质（降低分辨率/特效）；GPU 负载均衡。

### HW-02e GPU 绑核 / 降频
- 典型原因：GPU 多核绑定策略错误；高温触发 GPU 降频；负载不均。
- 典型影响：图形性能劣化；游戏/视频卡顿；渲染延迟增加。
- 故障注入：模拟 GPU 多核绑定异常；注入 GPU 降频事件；构造 GPU 负载不均。
- 日志/Trace：GPU 核心使用率统计；GPU 频率日志；渲染耗时曲线。
- 消减建议：GPU 调度器负载均衡；动态频率调整（DFS）策略优化；关键场景预留 GPU 性能预算。

## HW-03 TP（触摸屏）故障

### HW-03a TP 未注册 / 重复注册 / 参数非法
- 典型原因：驱动加载失败、TP 设备树配置错误、I2C/SPI 通信失败；重复加载驱动；固件版本不匹配。
- 典型影响：开机卡在菊花界面；Power 键响应但其他物理按键不响应；虚拟按键不响应；UI 界面不响应；滑动划线断线或变为点击；x 秒后整机重启。
- 故障注入：移除 TP 驱动模块；构造 I2C/SPI 通信失败；注入非法 TP 参数；重复注册 TP 设备。
- 日志/Trace：input 子系统注册日志（`input_register_device`）；I2C/SPI 错误日志；kernel panic/oops；watchdog 重启日志。
- 消减建议：TP 驱动加载失败时降级（启用虚拟按键/语音交互）；开机流程不阻塞于 TP 初始化；参数合法性校验；重复注册检测。

## HW-04 内存故障

### HW-04a 内存不足（Low Memory）
- 典型原因：应用内存泄漏、系统缓存过大、后台进程过多；内存分配慢路径、swap 扇入扇出导致 IO 升高。
- 典型影响：物理按键/虚拟按键/滑动界面均响应但卡顿明显；VM 重启；指纹解锁提示首次进入系统需输入密码；卡顿 x 分钟后整机重启；低于 LMK/OOM 门限时进程被杀死。
- 故障注入：循环 malloc 不释放至内存耗尽；构造大量后台进程占用内存；模拟低内存场景（drop_caches + 内存分配压力）。
- 日志/Trace：LMK 杀进程日志（`lowmemorykiller`）；kernel oom 日志；swap 活动统计；HiAppEvent 内存事件；PSS 曲线。
- 消减建议：内存水位监控与主动释放（缓存清理）；LMK 策略优化（优先杀后台非关键应用）；关键服务内存预算与保护；swap/zram 优化。

### HW-04b 内存泄漏（Native / JS / 内核）
- 典型原因：new/malloc 与 delete/free 不配对；异常分支跳过释放；循环中持续分配；JS 闭包/监听器未移除；内核模块内存泄漏。
- 典型影响：卡顿、应用闪退、VM 重启、整机重启；系统可用内存持续下降。
- 故障注入：循环触发可疑分配路径；hidumper --mem 采样对比；ASan/LeakWatcher 检测；构造内核模块泄漏场景。
- 日志/Trace：HiAppEvent 资源泄漏事件（pss 超限）；hidumper 内存采样曲线；ASan leak 报告；kernel kmemleak 报告。
- 消减建议：RAII/智能指针统一管理；泄漏路径补释放；HiAppEvent 订阅泄漏事件并设阈值告警；内核 kmemleak 定期扫描。

### HW-04c 内存耗尽（OOM）
- 典型原因：内存分配请求超过系统可用内存；大内存分配失败未处理；内存碎片导致连续大内存无法分配。
- 典型影响：系统触发 OOM，进程被强制退出；VM 重启；整机重启；关键服务崩溃。
- 故障注入：构造超大内存分配请求；碎片化内存后申请连续大内存；多进程并发大量分配。
- 日志/Trace：kernel oom-killer 日志；进程被杀事件；系统重启日志；内存碎片统计（/proc/buddyinfo）。
- 消减建议：大内存分配前预检查可用内存；分配失败降级路径（分块分配/压缩）；内存碎片整理（compaction）；关键服务预留内存（memory reserve）。

### HW-04d 内存越界（Out-of-Bounds）
- 典型原因：数组/缓冲区越界访问；指针算术错误；栈溢出；堆溢出。
- 典型影响：进程内存被踩，导致崩溃、数据错乱、安全漏洞；VM 重启；整机重启。
- 故障注入：构造越界读写；栈溢出（递归无出口/大栈帧）；堆溢出（大拷贝到小缓冲区）；ASan/HWASAN 检测。
- 日志/Trace：ASAN/HWASAN 报告；faultlog SIGSEGV 栈；kernel oops（内核越界）；栈溢出可见大量重复栈帧。
- 消减建议：边界检查（数组下标、长度校验）；安全函数（snprintf/strlcpy）；栈深度保护（stack canary）；ASan/HWASAN 开发期检测。

### HW-04e 内存碎片（Memory Fragmentation）
- 典型原因：长时间运行后内存分配/释放模式导致碎片；大量小对象分配后释放不均。
- 典型影响：分配连续大内存进入慢路径或失败；系统性能下降；OOM 提前触发。
- 故障注入：长时间运行后申请大内存；构造特定分配/释放序列产生碎片；监控 buddyinfo。
- 日志/Trace：/proc/buddyinfo 碎片统计；分配失败日志（order-N 分配失败）；compaction 活动日志。
- 消减建议：内存分配器优化（slab/SLUB）；大内存预留；定期内存整理（compaction）；关键服务使用 CMA（Contiguous Memory Allocator）。

### HW-04f 局部/全局引用溢出（JNI Reference Overflow）
- 典型原因：JNI 局部引用（LocalRef）泄露超过 8388608；全局引用（GlobalRef）泄露超过 51200；未正确 DeleteLocalRef/DeleteGlobalRef。
- 典型影响：JNI 引用表溢出异常退出；应用闪退；Native 层崩溃。
- 故障注入：循环创建 JNI 引用不释放；构造引用表溢出场景。
- 日志/Trace：JNI 引用溢出日志（`Local reference table overflow`、`Global reference table overflow`）；faultlog 崩溃栈。
- 消减建议：JNI 引用生命周期严格管理（RAII 封装）；局部引用及时释放；全局引用上限监控；引用泄漏检测工具。

## HW-05 存储故障（EMMC / UFS / SSD）

### HW-05a 存储初始化失败（EMMC / UFS / SSD）
- 典型原因：存储芯片故障、固件损坏、供电异常、通信总线错误；bootloader 无法识别存储。
- 典型影响：开机卡在菊花界面；系统无法引导；设备变砖。
- 故障注入：模拟存储芯片无响应；构造固件损坏；断开存储供电。
- 日志/Trace：bootloader 存储检测日志（`mmc_init`、`ufs_init`）；kernel 存储驱动错误日志；panic/oops。
- 消减建议：存储双备份（A/B 分区）；bootloader 存储检测失败后进入恢复模式；关键数据多副本；出厂测试覆盖存储兼容性。

### HW-05b 存储读写失败 / 延迟（EMMC / UFS / SSD）
- 典型原因：存储芯片坏块、磨损均衡失败、ECC 错误、通信错误；高温/低温导致存储性能下降。
- 典型影响：开机卡在菊花界面；应用启动/切换卡顿；写超时触发系统 panic；数据丢失。
- 故障注入：模拟存储读/写失败（注入错误响应）；构造存储延迟（延迟响应 ACK）；构造坏块场景。
- 日志/Trace：存储驱动错误日志（`mmc_read`、`ufs_read`）；I/O 错误统计（/sys/block/xxx/ioerr_cnt）；panic/oops。
- 消减建议：ECC 纠错与重试；坏块管理（BBM）；读写超时监控；关键数据 CRC 校验；存储健康度监控（SMART）。

### HW-05c SCSI / UFS / SSD 协议错误
- 典型原因：SCSI 命令响应状态错误（CHECK_CONDITION、BUSY、QUEUE_FULL 等）；UFSHCD 状态错误；SCSI 消息/控制器/驱动错误。
- 典型影响：冻屏后 watchdog 重启；系统变为只读；系统立即重启；所有读写操作阻塞。
- 故障注入：注入 SCSI 状态错误（`scsi_inject_fault`）；构造 UFSHCD 复位中状态；模拟 SCSI 消息连续异常。
- 日志/Trace：SCSI 错误日志（`scsi_cmd`、`status code`）；UFSHCD 状态日志；watchdog 超时事件；系统重启日志。
- 消减建议：SCSI 错误重试与降级；UFSHCD 状态恢复机制；只读文件系统检测与修复（fsck）；watchdog 保护；关键数据多副本。

### HW-05d MBR / 分区表读取失败
- 典型原因：MBR 损坏、分区表错误、存储初始化失败；恶意篡改分区表。
- 典型影响：开机启动失败；系统无法识别分区；数据丢失。
- 故障注入：篡改 MBR 签名；删除分区表；构造无效分区项。
- 日志/Trace：kernel 分区检测日志（`invalid partition table`、`no partition found`）；bootloader 日志。
- 消减建议：GPT 分区表备份（首尾双备份）；MBR/GPT 校验和验证；损坏时进入恢复模式；关键分区冗余。

### HW-05e IOWait 高
- 典型原因：存储 IO 瓶颈、大量并发 IO、后台 IO 风暴、存储性能下降；sync 操作挂住。
- 典型影响：黑屏、桌面不显示；物理键/虚拟键不响应；只能长按电源键恢复；系统卡顿。
- 故障注入：构造大量并发 IO（dd + sync）；模拟存储延迟；后台 IO 风暴。
- 日志/Trace：iowait 统计（top、vmstat）；IO 调度器日志；watchdog 超时事件；system_server ANR trace。
- 消减建议：IO 调度优化（mq-deadline/none）；后台 IO 限速（ionice）；sync 超时保护；关键路径异步 IO；iowait 监控与告警。

## HW-06 数据库故障（底层存储视角）

### HW-06a 数据库损坏 / 丢失 / 全零 / 事务不一致
- 典型原因：掉电半写、存储故障、进程崩溃时未刷盘、恶意篡改；多文件非事务更新。
- 典型影响：数据库访问失败；上层业务失效；数据丢失；启动崩溃。
- 故障注入：篡改数据库文件头部；截断数据库文件；构造全零文件；注入事务中断。
- 日志/Trace：数据库打开失败日志（`database disk image is malformed`）；RDB store open 失败 errcode；HiSysEvent 数据库损坏事件。
- 消减建议：数据库文件 CRC/校验和；写前日志（WAL）；损坏时备份恢复/删除重建；重要数据多副本；启动路径校验与自愈。

### HW-06b 分布式数据库数据不一致
- 典型原因：网络分区、同步冲突、时钟不同步、并发写冲突；同步过程中断。
- 典型影响：两端业务处理结果存在差异；数据错乱；用户体验劣化。
- 故障注入：构造网络分区；注入同步冲突；模拟时钟偏移；并发写同一记录。
- 日志/Trace：分布式数据库同步日志（`sync conflict`、`version mismatch`）；数据一致性校验日志；HiSysEvent 同步异常事件。
- 消减建议：向量时钟/版本号冲突解决；最后写者胜出（LWW）或业务层合并；同步完整性校验；不一致检测与修复工具。

## 二、驱动故障（Driver）

### DRV-01 EC hang 死
- 典型原因：EC 无法处理鼠标、键盘等请求；构造 EC hang 住异常。
- 典型影响：开机失败；键盘/鼠标无响应；系统卡顿。
- 故障注入：EC hang 住异常；观察系统容错能力。
- 日志/Trace：EC 日志；驱动日志；系统日志；错误日志；功能状态日志。
- 消减建议：EC 超时检测；EC 复位机制；错误恢复；功能降级；稳定性测试。

### DRV-02 驱动崩溃
- 典型原因：驱动使用过程中挂掉；空指针、越界、除零、非法指令；栈溢出；资源耗尽。
- 典型影响：驱动功能异常；设备无法使用；系统崩溃。
- 故障注入：驱动崩溃；观察系统行为。
- 日志/Trace：驱动日志；崩溃日志；系统日志；错误日志；功能状态日志。
- 消减建议：驱动健壮性；异常捕获；资源管理；错误恢复；功能降级；稳定性测试。

### DRV-03 驱动丢失
- 典型原因：驱动丢失，导致上层业务无响应；驱动未加载；驱动被卸载；驱动文件损坏。
- 典型影响：设备无法使用；业务无响应；系统异常。
- 故障注入：驱动丢失；观察上层业务。
- 日志/Trace：驱动日志；设备日志；系统日志；错误日志；功能状态日志。
- 消减建议：驱动自动加载；驱动完整性校验；驱动备份；错误恢复；功能降级；稳定性测试。

### DRV-04 驱动加载延迟
- 典型原因：驱动延迟加载，导致上层业务无响应；依赖未就绪；资源不足；加载超时。
- 典型影响：设备初始化延迟；业务超时；用户体验劣化。
- 故障注入：驱动延迟加载；观察上层业务。
- 日志/Trace：驱动日志；加载日志；系统日志；错误日志；功能状态日志。
- 消减建议：驱动加载超时保护；依赖管理；资源预检查；异步加载；错误恢复；功能降级；稳定性测试。

### DRV-05 驱动管理进程异常
- 典型原因：通过 kill 操作杀掉 devmgr/devhost 进程导致异常；进程崩溃；资源耗尽。
- 典型影响：驱动管理异常；设备无法管理；系统不稳定。
- 故障注入：devmgr/devhost kill；观察驱动管理。
- 日志/Trace：驱动管理日志；进程日志；系统日志；错误日志；功能状态日志。
- 消减建议：进程保活；驱动管理状态保存；错误恢复；功能降级；稳定性测试。

### DRV-06 驱动模块加载达到上限
- 典型原因：模块数量达到 OS 上限；内存不足；资源耗尽。
- 典型影响：驱动模块加载失败；新设备无法使用；系统不稳定。
- 故障注入：模块数量达到上限；观察驱动加载。
- 日志/Trace：驱动日志；模块日志；系统日志；错误日志；功能状态日志。
- 消减建议：模块数量上限校验；资源管理；错误处理；功能降级；稳定性测试。

### DRV-07 驱动内存泄漏
- 典型原因：驱动内存泄漏；malloc 后未 free；异常分支跳过释放。
- 典型影响：系统内存耗尽；性能下降；系统崩溃。
- 故障注入：驱动内存泄漏；观察系统内存。
- 日志/Trace：驱动日志；内存日志；系统日志；错误日志；功能状态日志。
- 消减建议：内存管理；泄漏检测；资源监控；错误恢复；功能降级；稳定性测试。

### DRV-08 加载恶意驱动
- 典型原因：加载恶意驱动，导致驱动挂掉等；签名验证失败；来源不可信。
- 典型影响：系统安全漏洞；驱动异常；数据泄露。
- 故障注入：加载恶意驱动；观察系统安全。
- 日志/Trace：驱动日志；安全日志；系统日志；错误日志；功能状态日志。
- 消减建议：驱动签名验证；来源白名单；安全审计；错误恢复；功能降级；稳定性测试。
