# 虚拟化故障模式（Virtualization / Container）

本类覆盖 **虚拟机生命周期、容器异常、跨虚拟机共享内存、跨虚拟机快速通知、虚拟化时钟/中断、虚拟设备** 等虚拟化层故障，适用于容器（卓易通/出境易）、虚拟化子系统、跨虚拟机通信的模块分析。

---

## VM-01 虚拟机生命周期故障

### VM-01a 虚拟机异常销毁（VM Abnormal Destruction）
- 典型原因：kill 虚拟机进程；宿主机资源不足强制回收；虚拟机内部崩溃；管理器错误销毁。
- 典型影响：虚拟机内业务中断；数据丢失；依赖该虚拟机的服务不可用；级联故障。
- 故障注入：kill 虚拟机进程；构造宿主机资源不足；虚拟机内部注入崩溃；管理器错误调用销毁。
- 日志/Trace：虚拟机销毁日志（`vm destroy`、`vm exit`）；宿主机资源日志；虚拟机内部崩溃日志；管理器操作日志。
- 消减建议：虚拟机销毁前数据持久化；关键数据实时同步到宿主机；虚拟机保活机制；销毁后自动重建；业务层感知虚拟机状态。

### VM-01b 虚拟机异常挂死（VM Hang）
- 典型原因：虚拟机内部死锁；IO 阻塞；CPU 资源被宿主机抢占；虚拟化驱动故障；内存不足。
- 典型影响：虚拟机内业务无响应；虚拟机无法被正常管理；宿主机资源被占用；只能强制销毁。
- 故障注入：虚拟机内部注入死锁；IO 无限延迟；宿主机 CPU 抢占；驱动故障；内存不足。
- 日志/Trace：虚拟机状态日志（`vm hang`、`vm unresponsive`）；宿主机资源日志；虚拟机内部线程 dump；watchdog 超时日志。
- 消减建议：虚拟机内部 watchdog；宿主机资源监控；虚拟机 IO 超时保护；挂死检测与自动恢复；强制销毁后重建。

### VM-01c 虚拟机异常停止（VM Abnormal Stop）
- 典型原因：虚拟机内部发生 data abort；非法指令；内存访问错误；虚拟化异常未处理。
- 典型影响：虚拟机停止运行；业务中断；数据可能损坏；需要重启恢复。
- 故障注入：虚拟机内部注入 data abort；非法指令；内存访问错误；虚拟化异常。
- 日志/Trace：虚拟机异常日志（`data abort`、`undefined instruction`）；虚拟化异常日志；内存错误日志；faultlog。
- 消减建议：虚拟机内存隔离；异常处理与恢复；data abort 后数据校验；自动重启；异常信息上报。

### VM-01d 虚拟机启动或创建失败（VM Start/Create Failure）
- 典型原因：镜像损坏、资源不足（内存/CPU/存储）、配置错误、依赖服务未就绪、启动过程中异常中止。
- 典型影响：虚拟机无法启动；业务不可用；容器（如卓易通）无法启动；级联故障。
- 故障注入：镜像损坏；资源不足；配置错误；依赖服务未就绪；启动过程中 kill 进程。
- 日志/Trace：虚拟机启动日志（`vm start failed`、`vm create failed`）；资源不足日志；配置错误日志；依赖服务日志。
- 消减建议：镜像完整性校验；资源预检查；配置合法性校验；依赖服务就绪检测；启动超时保护；启动失败降级（提示用户/使用备用镜像）。

### VM-01e 虚拟机负载过高（VM Overload）
- 典型原因：虚拟机内运行压力测试；文件系统压测；CPU/内存/IO 密集型任务；宿主机资源分配不足。
- 典型影响：虚拟机内业务卡顿；宿主机资源被耗尽；其他虚拟机受影响；虚拟机被宿主机限制。
- 故障注入：虚拟机内运行压力测试；文件系统压测；CPU/内存密集型任务；宿主机资源限制。
- 日志/Trace：虚拟机资源使用日志（CPU/内存/IO）；宿主机资源日志；虚拟机性能日志；资源限制日志。
- 消减建议：虚拟机资源配额（cgroups）；资源监控与告警；过载时自动扩容或限流；宿主机资源隔离；虚拟机优先级管理。

## VM-02 容器故障（Container Fault）

### VM-02a 容器通讯异常（Container Communication Failure）
- 典型原因：容器内外交互无响应；网络命名空间隔离；虚拟网卡故障；iptables 规则错误；容器内服务未启动。
- 典型影响：容器内外业务无法通信；容器内应用无法访问外部网络；外部无法访问容器内服务；业务中断。
- 故障注入：断开容器网络；虚拟网卡故障；iptables 规则错误；容器内服务未启动；构造通讯超时。
- 日志/Trace：容器网络日志（`veth`、`bridge`）；iptables 日志；容器内服务日志；通讯超时日志。
- 消减建议：容器网络健康检查；虚拟网卡冗余；iptables 规则校验；容器内服务就绪检测；通讯超时重试；网络隔离降级。

### VM-02b 容器驱动异常（Container Driver Failure）
- 典型原因：虚拟化驱动崩溃；驱动与内核版本不兼容；驱动资源耗尽；驱动配置错误。
- 典型影响：容器无法访问硬件；容器内业务失败；宿主机驱动受影响；级联故障。
- 故障注入：卸载虚拟化驱动；驱动崩溃；驱动资源耗尽；驱动配置错误。
- 日志/Trace：驱动日志（`driver crash`、`driver init failed`）；内核日志；容器日志；硬件访问日志。
- 消减建议：驱动版本兼容性校验；驱动资源监控；驱动崩溃自动恢复；容器硬件访问隔离；驱动配置校验。

### VM-02c 容器镜像异常（Container Image Failure）
- 典型原因：镜像损坏、镜像下载失败、镜像校验失败、镜像格式不支持、镜像层缺失。
- 典型影响：容器无法启动；业务不可用；容器反复拉取镜像；存储空间耗尽。
- 故障注入：镜像文件损坏；镜像下载中断；镜像校验失败；镜像层缺失；镜像格式错误。
- 日志/Trace：镜像日志（`image pull failed`、`image corrupt`）；下载日志；校验日志；容器启动日志。
- 消减建议：镜像完整性校验（SHA256）；镜像下载断点续传；镜像缓存与备份；镜像格式校验；镜像层缺失检测；启动失败降级。

## VM-03 跨虚拟机共享内存故障

### VM-03a 多进程/线程并发访问同一段静态共享内存（Shared Memory Concurrent Access）
- 典型原因：多个进程/线程同时读写同一段共享内存；无同步机制；锁粒度错误；死锁。
- 典型影响：数据竞争；数据损坏；业务结果不一致；崩溃。
- 故障注入：多进程/线程并发读写共享内存；移除同步机制；构造数据竞争；死锁注入。
- 日志/Trace：共享内存访问日志；数据竞争检测（TSan）；崩溃日志；数据不一致日志。
- 消减建议：共享内存访问同步（mutex/sem/spinlock）；原子操作；数据竞争检测工具（TSan）；共享内存隔离；访问权限控制。

### VM-03b 重复释放静态共享内存（Double Free Shared Memory）
- 典型原因：多个进程/线程重复释放同一段共享内存；释放后未标记；引用计数错误。
- 典型影响：内存损坏；其他进程崩溃；数据丢失；系统不稳定。
- 故障注入：重复释放共享内存；引用计数错误；释放后再次释放。
- 日志/Trace：内存错误日志（`double free`、`invalid pointer`）；崩溃日志；共享内存管理日志。
- 消减建议：共享内存引用计数管理；释放后标记无效；RAII 封装；释放前校验所有权；内存损坏检测。

### VM-03c 释放后再次使用静态共享内存（Use-After-Free Shared Memory）
- 典型原因：共享内存释放后，其他进程/线程仍持有指针并访问；生命周期管理错误。
- 典型影响：数据损坏；崩溃；安全漏洞；业务结果错误。
- 故障注入：释放共享内存后其他进程访问；延迟释放；生命周期管理错误。
- 日志/Trace：内存错误日志（`use-after-free`）；崩溃日志；ASan 报告；共享内存生命周期日志。
- 消减建议：共享内存生命周期管理（引用计数）；释放后指针置空；ASan 检测；访问前校验有效性；弱引用机制。

### VM-03d 创建动态有名共享内存失败（Dynamic Named Shared Memory Creation Failure）
- 典型原因：物理内存耗尽；共享内存名称冲突；权限不足；系统配置限制；虚拟机资源配额不足。
- 典型影响：共享内存创建失败；业务无法启动；数据无法共享；级联故障。
- 故障注入：耗尽物理内存；名称冲突；权限注入；资源配额限制；系统配置限制。
- 日志/Trace：共享内存创建日志（`shm_open failed`、`mmap failed`）；内存日志；权限日志；配额日志。
- 消减建议：共享内存创建前资源预检查；名称唯一性校验；权限预校验；资源配额监控；创建失败降级；内存不足提示。

## VM-04 跨虚拟机快速通知机制故障（vNotify）

### VM-04a vNotify 通道资源耗尽（vNotify Channel Exhaustion）
- 典型原因：创建 vNotify 通道直至共享内存耗尽；资源泄漏；通道未关闭；配额不足。
- 典型影响：无法创建新通道；通知机制失效；业务中断；级联故障。
- 故障注入：循环创建 vNotify 通道不关闭；共享内存耗尽；资源泄漏；配额限制。
- 日志/Trace：vNotify 创建日志（`vnotify_create failed`）；共享内存日志；资源耗尽日志；通道数量统计。
- 消减建议：vNotify 通道上限控制；资源监控；泄漏检测；通道复用；资源配额管理；创建失败降级。

### VM-04b uapp 进程异常退出后 vNotify 通道未清理（vNotify Channel Leak on uapp Exit）
- 典型原因：host 上某个 uapp 进程创建多个 vNotify 通道，进程异常退出后通道未自动清理；资源泄漏。
- 典型影响：vNotify 通道泄漏；共享内存耗尽；其他进程无法创建通道；业务中断。
- 故障注入：uapp 进程创建多个通道后异常退出；kill uapp 进程；观察通道泄漏。
- 日志/Trace：vNotify 通道日志；uapp 进程退出日志；共享内存泄漏日志；通道数量监控。
- 消减建议：uapp 进程退出时自动清理 vNotify 通道；进程监控与通道关联；通道生命周期管理；泄漏检测与自动回收；资源上限告警。

## VM-05 虚拟化时钟故障

### VM-05a Host 时钟跳变（Host Clock Jump）
- 典型原因：NTP 同步导致时钟向前/向后跳变；系统时间被手动修改；RTC 电池耗尽；虚拟机迁移后时钟差异。
- 典型影响：虚拟机内时间不一致；定时器失效；日志时间错乱；证书校验失败；业务逻辑错误（如超时判断）。
- 故障注入：修改 host 系统时间（向前/向后跳变）；NTP 同步注入；RTC 故障模拟；虚拟机迁移。
- 日志/Trace：时钟变化日志（`time jump`、`clock skew`）；NTP 日志；定时器日志；证书校验日志；业务超时日志。
- 消减建议：虚拟机时间同步机制（virtio-clock/PTP）；定时器使用单调时钟（CLOCK_MONOTONIC）；时钟跳变检测与告警；业务逻辑不依赖绝对时间；NTP 平滑同步（adjtime）。

## VM-06 虚拟化中断故障

### VM-06a Guest 发送到 Host 的中断丢失（Guest-to-Host Interrupt Loss）
- 典型原因：中断被误屏蔽；虚拟化层中断注入失败；中断路由错误；中断风暴导致丢失。
- 典型影响：Host 未收到中断；设备事件丢失；业务超时；数据不一致。
- 故障注入：屏蔽中断注入；构造中断风暴；中断路由错误；虚拟化层故障注入。
- 日志/Trace：中断日志（`interrupt lost`、`interrupt injection failed`）；虚拟化层日志；设备事件日志；超时日志。
- 消减建议：中断注入校验；中断路由冗余；中断风暴检测与限流；中断丢失检测与重发；虚拟化层健康检查。

### VM-06b Guest 频繁发送 Host 中断（Guest Interrupt Storm）
- 典型原因：Guest 内设备驱动异常；中断处理程序错误；设备故障导致频繁中断；虚拟化层中断聚合失效。
- 典型影响：中断拥塞；Host CPU 被中断占满；其他设备中断丢失；系统卡顿；中断信号丢失。
- 故障注入：Guest 内构造频繁中断；中断聚合失效；设备故障模拟。
- 日志/Trace：中断频率日志（`interrupt rate`）；CPU 中断时间统计；虚拟化层日志；设备日志。
- 消减建议：中断聚合（coalescing）；中断频率限制；中断处理程序优化；虚拟化层中断限流；设备故障检测与隔离。

### VM-06c Host 频繁发送 Host/Guest 中断（Host Interrupt Storm）
- 典型原因：Host 内设备驱动异常；中断处理程序错误；设备故障导致频繁中断；虚拟化层中断聚合失效。
- 典型影响：中断拥塞；Guest CPU 被中断占满；其他设备中断丢失；系统卡顿；中断信号丢失。
- 故障注入：Host 内构造频繁中断；中断聚合失效；设备故障模拟。
- 日志/Trace：中断频率日志；CPU 中断时间统计；虚拟化层日志；设备日志。
- 消减建议：同 VM-06b 消减建议；Host/Guest 中断隔离；中断优先级管理。

### VM-06d Guest 不处理 Host 中断（Guest Ignores Host Interrupt）
- 典型原因：Guest 中断处理程序未注册；中断被屏蔽；Guest 内核故障；中断转发失败。
- 典型影响：Host 收到中断但 Guest 不转发；设备事件丢失；业务超时；数据不一致。
- 故障注入：Guest 内屏蔽中断；移除中断处理程序；Guest 内核故障；中断转发失败。
- 日志/Trace：中断日志；Guest 中断处理日志；虚拟化层日志；设备事件日志；超时日志。
- 消减建议：Guest 中断处理程序注册校验；中断屏蔽检测；中断转发监控；超时后重发中断；Guest 内核健康检查。

### VM-06e Guest 处理中断时发生异常（Guest Interrupt Handler Exception）
- 典型原因：Guest 中断处理程序中存在 bug（空指针、越界、死锁）；中断上下文错误；栈溢出。
- 典型影响：Host 收到 Guest 中断但 Guest 处理异常；设备事件丢失；Guest 崩溃；业务中断。
- 故障注入：Guest 中断处理程序注入空指针/越界/死锁；中断上下文错误；栈溢出。
- 日志/Trace：Guest 崩溃日志；中断处理程序日志；虚拟化层日志；faultlog；watchdog 日志。
- 消减建议：中断处理程序健壮性（边界检查、异常处理）；中断上下文隔离；栈深度保护；中断处理超时监控；崩溃后自动恢复。
