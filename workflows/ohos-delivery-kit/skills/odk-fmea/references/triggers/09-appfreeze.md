# 主线程卡死 / AppFreeze 故障模式 触发索引

> 两级加载第一级：只读本表做扫描判定；条目触发条件命中后，到 [../09-appfreeze.md](../09-appfreeze.md) 读取该 `### ID` 条目详情（大文件可用 Read offset/limit 按锚点局部读）。

| ID | 故障模式 | 触发条件（可判定的代码/设计特征） |
|---|---|---|
| A-01 | 主线程执行耗时任务 | 主线程做大粒度计算、文件/数据库 IO、同步网络请求；长任务未拆分让出事件循环（watchdog 判活任务无法执行） |
| A-02 | 主线程同步网络 / 资源加载 | Image 组件设置 syncLoad=true 同步加载网络图片；主线程同步等待资源且无超时与占位降级 |
| A-03 | 跨线程同步任务互锁 | 工作线程 PostSyncTask 到主线程并等待完成，同时主线程也在等该工作线程（或经 IPC 形成跨进程互锁环） |
| A-04 | 输入响应超时（APP_INPUT_BLOCK） | 输入事件处理链路（点击分发依赖线程）可被阻塞（5s/8s 无响应即触发）；输入路径存在同步等待 |
| A-05 | 同步等待无超时保护 | 同步 IPC/锁/条件变量/future.get 无超时；或超时设置超过 watchdog 6s 判活窗口 |
