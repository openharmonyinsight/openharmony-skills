# 网络与分布式故障模式 触发索引

> 两级加载第一级：只读本表做扫描判定；条目触发条件命中后，到 [../16-network-distributed.md](../16-network-distributed.md) 读取该 `### ID` 条目详情（大文件可用 Read offset/limit 按锚点局部读）。

| ID | 故障模式 | 触发条件（可判定的代码/设计特征） |
|---|---|---|
| NET-01a | BLE 广播异常 | 设备发现走 BLE advertising 接口（广播 interval/tx power 配置）；无蓝牙开关/权限预检、广播失败重试或广播参数自适应与降级路径 |
| NET-01b | COAP 广播异常 | 设备发现依赖 COAP 服务（coap start、多播组 multicast、监听端口）；端口固定分配或多播配置无校验；无服务自启动保活或防火墙白名单 |
| NET-01c | BLE 连接失败 | 组网/传输经 BLE GATT 建链（connect、配对 pair、RSSI、GATT service 就绪）；无连接重试退避、RSSI 监控或 GATT 就绪检测与降级 |
| NET-01d | WiFi P2P 连接失败 | 办公/出行场景组网、投屏走 WiFi P2P（P2P group/GO 协商、频段、密码 connect）；无 WiFi 状态检测、P2P 配置自动协商或频段自适应 |
| NET-01e | WiFi AP 连接失败 | 代码执行 WiFi AP 接入（SSID/密码校验、association、DHCP 取 IP、频段匹配）；无 DHCP 失败重试、IP 冲突检测或连接失败提示 |
| NET-01f | 跨设备同步失败（剪切板/大数据传输） | 剪切板跨端推送经 SoftBus 通道（softbus transfer）；涉及 kill 软总线进程、对端离线或大数据整包传输；无推送失败重试、分片与超时保护 |
| NET-02a | 网络错包（Corrupt Packet） | 收包路径依赖 4G（rmnet0）/WiFi（wlan0）质量且无校验（RX/CRC errors 统计、rphone corrupt 注入场景）；无错包率监控或 4G/WiFi 自动切换 |
| NET-02b | 网络延迟（High Latency） | 业务请求对 RTT 时延敏感（ping RTT、TCP 重传、应用超时）；涉及 rphone delay 注入、基站/信道拥塞场景；无 RTT 统计、超时重试退避或弱网降级 |
| NET-02c | 网络丢包（Packet Loss） | 代码消费或依赖 tcp_retransmits/RX dropped 统计（rphone loss 注入、拥塞/弱信号场景）；无丢包率监控、应用层重传或实时业务 FEC 纠错 |
| NET-02d | 网络包重复（Duplicate Packet） | 接收处理无 TCP 序号去重或应用层幂等（rphone duplicate 注入、网络环路/路由错误场景）；无序号校验、幂等设计或重复包监控 |
| NET-02e | 网络包乱序（Packet Reorder） | 数据流依赖按序到达（TCP out-of-order、SACK、多路径/负载均衡场景）；无应用层序列号校验排序或乱序缓冲区 |
| NET-02f | 网络服务中断（Service Down） | 代码处理断网事件（link down/no carrier、WiFi/移动数据开关、SIM/APN 异常）；无网络状态监控自动恢复、WiFi/4G 切换或离线模式 |
| NET-02g | 网卡带宽受限（Bandwidth Limit） | 下载/视频业务假设充足带宽（downlimit/uplimit 限速、QoS、信道拥塞场景）；无码率/分辨率自适应、分片多线程下载或带宽监控 |
| NET-02h | 网络闪断（Network Flapping） | 连接状态随 link up/down 频繁翻转（WiFi 弱信号、4G 基站切换、ip link/route 循环注入）；无状态防抖 hysteresis、快速重连或断线恢复 |
| NET-02i | 下载大文件异常 | 业务含大文件持续下载（download failed、insufficient storage 场景）；无断点续传、MD5/SHA256 校验、存储空间预检查或下载进度保存 |
| CS-01a | 主动发现 | 业务调用主动发现接口（SoftBus/DeviceManager StartDiscovery 类）周期发起首次/非首次设备发现；无发现超时保护、重试或成功率统计打点 |
| CS-01b | 被动发现 | 设备侧以发布/广播多播响应方式被动可被发现（PublishService 类接口）；无广播/多播响应超时保护、响应限流或发现成功率监控 |
| CS-01c | 单一协议发现 | 发现链路固定绑定 BLE 或 COAP 单一协议（发布/订阅仅一种）；无协议超时保护、协议冗余备份或干扰环境检测与成功率监控 |
| CS-01d | 多设备混合协议发现 | 多设备发现并存 BLE 与 COAP 两协议并含协议切换逻辑；无协议切换策略、协议超时保护或设备兼容性处理 |
| CS-01e | 多设备发现 | 发现能力面向典型组网与最大组网规模（设备数量、网络环境变化）；无组网上限控制、发现超时保护或设备数量管理 |
| CS-02a | 长时间双端操作 | 双端长时间不间断操作持续触发数据同步/传输（网络波动下）；无 CRC/MD5 数据校验、超时重传或数据完整性监控 |
| CS-02b | 反复本地和远端切换 | 业务在本地与远端（分布式设备）数据源间反复切换并触发同步/传输；无切换防抖、切换状态保存或切换时延监控 |
| CS-02c | 反复对远端虚拟设备切换 | 操作目标在多个远端虚拟设备（virtual device）间反复切换并触发数据传输；无虚拟设备状态管理、健康检查或切换防抖 |
| CS-02d | 双端长时间数据传输 | 传输覆盖不同数据类型/大小及超大文件并长时间进行；无大数据分片、断点续传、传输进度保存或速率监控 |
| CS-03a | 全量同步和实时同步并发 | 同步框架允许全量同步与实时同步并发执行（大数据量全量+业务实时同步）；无同步优先级管理、资源配额或并发限流 |
| CS-03b | 同步过程中反复断网 | 同步任务执行中反复断网再恢复（人为断网、远距离断开、系统异常断网）；无断网检测、同步进度保存或恢复后自动续传 |
| CS-03c | 同步过程中反复丢包 | 同步链路在反复丢包/弱网拥塞下持续工作（丢包注入场景）；无丢包检测、超时重传或双端数据一致性校验 |
| CS-03d | 系统高负载进行数据同步 | 数据同步与高 CPU/内存/IO 负载并发（同步优先级低）；无同步限流、资源配额或高负载时降级策略 |
| CS-04a | 双端设备长时间添加/删除/修改文件 | 双端长时间对不同类型文件并发增删改并触发文件同步；无冲突解决、文件版本管理或并发操作隔离与完整性校验 |
| CS-04b | 大容量文件存储下添加/删除/修改文件 | 存储空间不足或大容量文件场景下仍执行文件增删改与同步；无存储空间预检查、大文件分片同步或空间不足暂停同步 |
| CS-05a | 长时间连接状态 | 已建组网连接长期在线并承载上层业务传输（含设备休眠唤醒、网络波动）；无连接心跳保活、连接质量监控或唤醒后连接恢复 |
| CS-05b | 反复连接和断开 | 场景含反复主动/被动连接断开再重连（网络波动、设备移动）；无断开重连、连接成功率监控或设备信息/缩略图完整性校验 |
| CS-05c | 最大设备组网 | 组网达规格上限且反复新增/删除设备（单一/混合组网）；无组网上限控制、设备发现超时或组网状态保存与传输异常检测 |
| CS-05d | 多次重启设备组网连接 | 多设备组网中部分设备多次重启（reboot）后需恢复组网；无重启后组网自动恢复、设备上线检测或恢复超时保护 |
| CS-05e | 双端设备反复亮灭屏设备组网 | 组网双端设备反复亮灭屏（电源管理影响发现与自组网）；无亮灭屏后组网恢复、发现超时保护或组网成功率监控 |
| CS-05f | 频繁进程重启组网 | 发现/连接/组网相关进程被频繁重启或 kill 注入；无进程保活（watchdog）、重启后组网状态恢复或进程健康检查 |
| DS-01a | 对端设备 MIC 不可用 | 业务使用对端设备麦克风（分布式音频采集、通话/录音 MIC）；无 MIC 状态与占用检测、权限预校验或降级到本端 MIC |
| DS-01b | 对端设备 Speaker 不可用 | 业务向对端扬声器输出音频（分布式通话/媒体播放 Speaker）；无 Speaker 状态/静音/占用检测、权限预校验或降级到本端 |
| DS-01c | 对端设备 Camera 不可用 | 业务调用对端摄像头（分布式视频通话/拍照 Camera）；无 Camera 状态与占用检测、权限预校验、隐私保护处理或降级本端 |
| DS-01d | 对端设备 Display 不可用 | 业务向对端显示器投屏输出（Display、HDMI/DP 连接、分辨率协商）；无 Display 状态与连接检测、分辨率自适应或降级本端显示 |
| DS-02a | 跨设备大数据传输失败 | 跨端粘贴传输大文件/图片经 SoftBus 大数据通道；无分片传输、断点续传、对端存储预检查、传输超时保护或通道健康检查 |
| DS-03a | 长时间连接状态 | 组网连接长期在线承载上层业务（如分布式文管浏览缩略图）且经历休眠唤醒/网络波动；无心跳保活或连接异常检测与恢复 |
| DS-03b | 反复连接和断开 | 反复建立/断开设备连接（主动与被动、设备移动、网络波动）；无重连退避、连接成功率监控或设备信息/缩略图完整性校验 |
| DS-03c | 最大设备组网 | 组网设备数达规格上限（反复新增/删除设备、单一或混合组网压力）；无组网上限控制、发现/连接重试或传输异常检测 |
| DS-03d | 多次重启设备组网连接 | 组网内设备整机多次重启后需重新上线组网；无重启后自动恢复组网、设备上线检测或恢复超时保护 |
| DS-03e | 双端设备反复亮灭屏设备组网 | 组网双端设备反复亮灭屏（电源状态切换影响发现/自组网）；无亮灭屏后组网恢复、发现超时保护或成功率监控 |
| DS-03f | 频繁进程重启组网 | softbus/组网相关进程被频繁重启或 kill 注入；无进程保活（watchdog/重启）、重启后组网状态恢复或发现/连接超时保护 |
| DS-04a | 主动发现 | 业务主动发起设备发现（DeviceManager/SoftBus 主动发现接口，首次与非首次、网络/设备状态变化）；无发现超时保护、重试或成功率监控 |
| DS-04b | 被动发现 | 设备以广播/多播响应对端发现请求（被动上线方式）；无广播/多播超时保护、响应限流或设备状态同步与成功率监控 |
| DS-04c | 单一协议发现 | 发现仅经 BLE 或 COAP 单一协议实现（无备用发现链路）；无协议超时保护、协议冗余或环境/干扰检测 |
| DS-04d | 多设备混合协议发现 | 多设备发现并存 BLE 与 COAP 且含协议切换/兼容逻辑；无切换策略、协议超时保护或设备兼容性测试覆盖 |
| DS-04e | 多设备发现 | 发现面向典型/最大组网规模多设备（设备数量与网络环境变化）；无组网上限控制、设备数量管理或发现超时保护 |
| DS-05a | 长时间双端操作 | 双端长时间不间断操作持续触发数据同步/传输（网络波动、设备状态变化）；无 CRC/MD5 校验、超时重传或数据完整性监控 |
| DS-05b | 反复本地和远端切换 | 业务在本地与远端数据源间反复切换并触发同步/传输；无切换防抖、切换状态保存或时延监控与异常恢复 |
| DS-05c | 反复对远端虚拟设备切换 | 操作目标在多个远端虚拟设备间反复切换并触发数据传输；无虚拟设备状态管理、健康检查或切换防抖与时延监控 |
| DS-05d | 双端长时间数据传输 | 长时传输覆盖不同数据类型/大小与超大文件；无分片、断点续传、传输进度保存或数据完整性校验与速率监控 |
| DS-06a | 全量同步和实时同步并发 | 全量同步与实时同步可并发执行（大数据量全量+业务实时）；无同步优先级、资源配额、冲突解决或并发限流 |
| DS-06b | 同步过程中反复断网 | 同步执行中反复断网再恢复（人为/远距离/系统异常断网）；无断网检测、同步进度保存或恢复后自动续传与已同步数据可用性校验 |
| DS-06c | 同步过程中反复丢包 | 同步链路在丢包/弱网拥塞下持续工作（丢包注入场景）；无丢包检测、超时重传或数据完整性校验 |
| DS-06d | 系统高负载进行数据同步 | 数据同步与高 CPU/内存/IO 负载并发执行；无同步限流、同步优先级管理或高负载降级与资源监控 |
| DS-07a | 双端设备长时间添加/删除/修改文件 | 双端长时间对不同类型文件并发增删改并触发文件同步；无冲突解决、文件版本管理或文件完整性校验 |
| DS-07b | 大容量文件存储下添加/删除/修改文件 | 存储空间不足/大容量文件场景下执行文件增删改与同步；无存储空间预检查、大文件分片同步或空间不足暂停同步 |
