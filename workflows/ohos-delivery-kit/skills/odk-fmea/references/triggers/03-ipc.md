# IPC 故障模式 触发索引

> 两级加载第一级：只读本表做扫描判定；条目触发条件命中后，到 [../03-ipc.md](../03-ipc.md) 读取该 `### ID` 条目详情（大文件可用 Read offset/limit 按锚点局部读）。

| ID | 故障模式 | 触发条件（可判定的代码/设计特征） |
|---|---|---|
| I-01 | 对端进程死亡 | 发起 IPC 调用未注册 OnRemoteDied 死亡通知；对端崩溃后句柄失效仍继续调用；无重连/降级分支 |
| I-02 | IPC 调用阻塞 / 超时 / ANR | 主线程发起同步 IPC；调用无超时与看门狗；对端处理慢或死锁场景无保护 |
| I-03 | 返回值未完整处理 | 只处理成功路径；errcode 未全枚举（无默认分支）；reply 未判空/未校验长度即读取 |
| I-04 | 序列化 / 反序列化不匹配 | Parcel/MessageParcel 读写顺序或类型不一致；接口升级无版本号兼容；读取前未校验剩余长度 |
| I-05 | 大数据传输超限 | 经 binder 传递大数组/位图（接近 1MB 事务上限）；未走 Ashmem/共享内存或分片；调用前无大小预估 |
| I-06 | 调用方身份 / 权限未校验 | Stub 端 onTransact 未校验调用方 UID/PID/AccessToken/权限；敏感接口无入口鉴权 |
| I-07 | Stub 端异常未捕获 | 服务端实现无统一 try-catch 入口；异常直接穿透 IPC 层（进程崩溃影响全部客户端） |
| I-08 | 回调注册泄漏 / 重复注册 | 注册回调后无注销配对；重复注册不去重；回调持强引用（释放后被回调 UAF） |
| I-09 | 嵌套同步 IPC 死锁 | A 同步调 B 且 B 同步回调 A（双向同步）；持锁期间发起同步 IPC |
| I-10 | 高频反复调用无降级措施 | 服务端接口无限流/去重/排队上限；客户端失败无退避约定（死循环重试或回调风暴可打满 IPC 线程池） |
| I-11 | 接口返回失败未处理（Interface Return Failure Unhandled） | 业务代码只处理 SUCCESS 分支；errcode 未映射降级策略；跨层传递时错误码被吞没或篡改 |
| I-12 | 接口无响应 / 调用 hang（Interface Unresponsive） | 同步调用无超时（对端死锁/网络分区下永久挂起）；未区分"失败"与"未响应"；调用方线程池无隔离 |
| I-13 | 剪切板 Service 异常（Clipboard Service Exception） | 使用 Pasteboard Service 或跨设备复制粘贴；依赖分布式服务就绪；剪贴数据无大小上限与格式校验 |
| I-14 | 消息无响应（Message No Response） | 消息发送无超时/重试；对端处理线程可死锁；消息队列可积压；已发送未确认状态无回滚 |
| I-15 | 消息内容错误（Message Content Error） | 消息序列化字段顺序/类型/版本不匹配；消息无 CRC 校验；业务层无幂等去重与乱序处理 |
| I-16 | 消息过载 / 流控失效（Message Overload / Flow Control Failure） | 消息生产速率可超消费速率且无令牌桶/背压/队列深度上限；队列满时无丢弃降级与告警 |
