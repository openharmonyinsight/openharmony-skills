# 方法论（AIAG-VDA 七步法）

> 本节自 SKILL.md 移入（渐进披露：SKILL.md 仅保留流程骨架，调用即全量载入的部分不再承载方法论正文）。

遵循 AIAG-VDA FMEA 七步法，核心是"自上而下 + 自下而上结合，通过网络（失效链）链接"：

- **结构分析（自上而下）**：把系统拆解为 系统 → 子系统 → 模块 → 组件/函数 的树状结构。
- **功能分析（自上而下）**：为每个结构元素定义功能（"刹车"的功能是"减速和停止"）。
- **故障分析（自下而上）**：对每个功能推导故障模式（"刹车失灵"），向上关联故障影响，向下关联故障原因，形成严密的失效链，确保无一遗漏。
- 随后做风险分析（现有预防与检出手段）与优化（优化建议），最后输出文档化的 FMEA 表格。
