# 线程与并发故障模式

### T-01 线程泄漏 / 线程对象生命周期
- 典型原因：Thread 子类对象销毁前未调用 NotifyExitSync/NotifyExitAsync，子线程继续运行并调用已销毁对象的虚函数（纯虚崩溃）；线程池销毁前未 Stop()；任务含无限循环永久占用线程；线程名超 16 字符被截断影响定位。
- 典型影响：线程句柄耗尽被系统杀死；虚函数调用崩溃；资源无法回收。
- 故障注入：反复创建/销毁线程对象观察线程数；析构后触发 Run。
- 日志/Trace：HiAppEvent 资源泄漏事件（线程数超限）；crash 栈落在纯虚函数；线程数 dump。
- 消减建议：析构前配对 NotifyExit/Stop；任务设执行超时；线程命名规范预留编号空间。

### T-02 死锁
- 典型原因：多锁获取顺序不一致；持锁期间调用外部接口/同步 IPC；锁与信号量混用；读写锁升级（读锁内申请写锁）。
- 典型影响：线程永久互等；主线程卷入则 AppFreeze，系统服务卷入则系统级冻结。
- 故障注入：并发压测触发交错时序；注入延迟放大竞争窗口。
- 日志/Trace：watchdog/THREAD_BLOCK 事件 + 全线程堆栈 dump 显示互等；TSA 编译告警。
- 消减建议：统一锁顺序（ACQUIRED_BEFORE/AFTER 注解）；缩小临界区；持锁不调外部；启用 -Wthread-safety。

### T-03 数据竞争
- 典型原因：共享变量无锁读写；容器遍历时并发修改；SafeMap 误用 operator[]（返回引用，写场景非线程安全）。
- 典型影响：数据错乱、偶发崩溃，时序相关难复现。
- 故障注入：多线程并发读写压测 + TSAN。
- 日志/Trace：TSAN 报告；异常数据日志。
- 消减建议：共享数据统一加锁或用线程安全容器（Insert/ReadVal/ChangeValueByLambda）；TSA 注解标注锁与数据关系。

### T-04 条件变量 / 信号量误用
- 典型原因：wait 未用 while 循环检查谓词（虚假唤醒）；超时参数单位错误；信号量 post/wait 不配对；notify 时未持锁导致唤醒丢失。
- 典型影响：偶发挂起或提前返回用脏数据；永久等待。
- 故障注入：高频唤醒/等待交错压测；注入虚假唤醒。
- 日志/Trace：等待超时日志；堆栈停在 __timedwait_cp/pthread_cond_timedwait。
- 消减建议：wait 一律 while(谓词) 形式；配对审计；超时参数统一封装。

### T-05 Timer 使用陷阱
- 典型原因：依赖 Timer 在系统休眠时唤醒（Timer 无法唤醒休眠系统）；相同 interval 的多个定时器复用 timerFd 导致时间偏差；Unregister 与回调触发临界竞争导致额外回调。
- 典型影响：定时任务丢失/延迟（休眠场景功能失效）；回调时序错乱。
- 故障注入：休眠唤醒后检查定时任务；同 interval 多定时器并发。
- 日志/Trace：定时触发时间戳与预期偏差日志。
- 消减建议：休眠场景改用可唤醒方案；interval 错开（±1ms）；回调做幂等处理。

### T-06 事件 / 消息循环积压与失控
- 典型原因：事件产生快于消费且无上限；Handler 在生命周期结束后仍响应事件；IOEventReactor 的 Run 线程在 Terminate 前退出。
- 典型影响：队列膨胀内存增长；过期事件操作已销毁对象（崩溃）；主循环被单条长消息独占导致判活失败（AppFreeze）。
- 故障注入：高频事件注入观察队列深度；销毁后立即投递事件。
- 日志/Trace：EventRunner 队列深度 dump；AppFreeze 日志主线程栈。
- 消减建议：队列设上限与丢弃策略；生命周期结束手动停止 Handler；Terminate 与线程退出顺序约束。
