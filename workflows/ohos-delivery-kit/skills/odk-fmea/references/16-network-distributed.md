# 网络与分布式通信故障模式（Network / Distributed）

本类覆盖 **BLE/COAP/WiFi P2P/AP 近场通信、4G/WiFi 远场网络质量、Socket** 网络层故障，**发现连接、数据传输、数据/文件同步、设备组网** 通信稳定性场景，以及 **虚拟设备、对端设备器件、跨设备同步** 分布式故障（合并自原 16、27、19；跨设备同步重复条目已去重）。

## 一、网络故障（近场/远场/Socket）

## NET-01 近场通信故障（Proximity Communication）

### NET-01a BLE 广播异常
- 典型原因：BLE 芯片故障、固件错误、射频干扰、权限未授予、蓝牙未开启；广播间隔/功率配置错误。
- 典型影响：办公、出行、家居（灭屏）场景设备发现失败；分布式业务无法启动。
- 故障注入：关闭蓝牙；模拟射频干扰；构造 BLE 广播失败；篡改广播参数。
- 日志/Trace：BLE 广播失败日志（`advertising failed`）；蓝牙状态日志；设备发现超时日志；HiSysEvent 蓝牙事件。
- 消减建议：BLE 广播失败重试；广播参数自适应（功率/间隔）；蓝牙状态监控；降级到 COAP/WiFi 发现；发现失败提示用户。

### NET-01b COAP 广播异常
- 典型原因：COAP 服务未启动、网络端口冲突、多播组配置错误、防火墙阻断；家居场景设备发现依赖 COAP。
- 典型影响：家居场景设备发现失败；IoT 设备无法被发现；分布式业务中断。
- 故障注入：关闭 COAP 服务；端口冲突；防火墙阻断多播；篡改 COAP 配置。
- 日志/Trace：COAP 服务日志（`coap start failed`）；端口冲突日志；多播错误日志；设备发现超时日志。
- 消减建议：COAP 服务自启动与保活；端口动态分配；多播组配置校验；防火墙白名单；降级到 BLE 发现。

### NET-01c BLE 连接失败
- 典型原因：对端设备蓝牙未开启、距离过远、射频干扰、配对失败、GATT 服务未就绪；华为分享场景依赖 BLE 建链。
- 典型影响：华为分享场景设备组网失败；文件传输失败；分布式业务中断。
- 故障注入：关闭对端蓝牙；模拟距离过远；射频干扰；GATT 服务未就绪。
- 日志/Trace：BLE 连接失败日志（`connection failed`、`GATT error`）；配对失败日志；距离/RSSI 日志。
- 消减建议：BLE 连接重试与退避；RSSI 监控与距离提示；配对流程健壮性；GATT 服务就绪检测；降级到 WiFi P2P。

### NET-01d WiFi P2P 连接失败
- 典型原因：WiFi 未开启、P2P 组配置错误、频段冲突、密码错误、设备不支持 P2P；办公/出行场景依赖 P2P。
- 典型影响：办公/出行场景设备组网失败；文件传输失败；投屏失败。
- 故障注入：关闭 WiFi；P2P 组配置错误；频段冲突；密码错误；设备不支持 P2P。
- 日志/Trace：P2P 连接失败日志（`p2p connect failed`）；WiFi 状态日志；频段冲突日志；密码错误日志。
- 消减建议：WiFi 状态检测与提示；P2P 配置自动协商；频段自适应；密码自动填充；降级到 WiFi AP/BLE。

### NET-01e WiFi AP 连接失败
- 典型原因：AP 未开启、SSID/密码错误、频段不匹配、DHCP 失败、IP 冲突；家居场景依赖 AP 连接。
- 典型影响：家居场景设备组网失败；设备无法接入网络；分布式业务中断。
- 故障注入：关闭 AP；SSID/密码错误；DHCP 失败；IP 冲突；频段不匹配。
- 日志/Trace：AP 连接失败日志（`association failed`、`dhcp failed`）；WiFi 状态日志；IP 冲突日志。
- 消减建议：AP 状态检测；SSID/密码校验；DHCP 失败重试；IP 冲突检测；频段自适应；连接失败提示用户。

### NET-01f 跨设备同步失败（剪切板/大数据传输）
- 典型原因：网络/软总线底层原因；对端设备离线；传输通道异常；数据过大超时；kill 软总线进程。
- 典型影响：复制内容无法推送，对端粘贴失败；文件/图片粘贴失败；跨设备业务中断。
- 故障注入：kill 软总线进程；断开网络；对端离线；构造大数据传输超时；传输通道异常。
- 日志/Trace：软总线传输日志（`softbus transfer failed`）；剪切板服务日志；网络错误日志；超时日志。
- 消减建议：剪切板服务感知推送失败后重试一次；仍失败则打点上报；大数据分片传输；传输超时保护；对端离线检测；降级到本地剪切板。

## NET-02 远场通信故障（Remote Communication）

### NET-02a 网络错包（Corrupt Packet）
- 典型原因：物理层干扰、驱动错误、硬件故障、协议栈错误；4G/WiFi 网络质量差。
- 典型影响：网络连接错误、扫描失败；网络连接中断、无信号/信号弱；应用上网异常。
- 故障注入：rphone 工具注入 `rNet fault=corrupt interface=netType ratio=20%`；netType（4G: rmnet0, WiFi: wlan0）。
- 日志/Trace：网络错误日志（`RX errors`、`CRC errors`）；协议栈错误日志；rphone 注入日志；应用网络错误日志。
- 消减建议：网络质量监控（丢包率/错包率）；自动切换网络（4G/WiFi）；错误包重传；应用层校验（CRC）；弱网提示用户。

### NET-02b 网络延迟（High Latency）
- 典型原因：网络拥塞、路由跳数过多、基站负载高、WiFi 信道干扰；服务器响应慢。
- 典型影响：网络无法连接、上网速率慢；网络接收/应用上网延迟；用户体验劣化。
- 故障注入：rphone 工具注入 `rNet fault=delay interface=netType time=2000ms`；netType（4G: rmnet0, WiFi: wlan0）。
- 日志/Trace：网络延迟日志（ping RTT）；TCP 重传日志；应用超时日志；rphone 注入日志。
- 消减建议：网络延迟监控（RTT 统计）；超时重试与退避；CDN/边缘节点加速；弱网降级（低画质/低帧率）；延迟提示用户。

### NET-02c 网络丢包（Packet Loss）
- 典型原因：网络拥塞、信号弱、物理层干扰、路由器 buffer 溢出；移动数据业务（2G/3G/4G）不可用。
- 典型影响：网络无法连接；网络接收错误、应用上网异常；TCP 重传增加、吞吐量下降；实时业务卡顿。
- 故障注入：rphone 工具注入 `rNet fault=loss interface=netType ratio=10%`；netType（4G: rmnet0, WiFi: wlan0）。
- 日志/Trace：丢包统计（`tcp_retransmits`、`RX dropped`）；TCP 拥塞窗口日志；应用超时日志；rphone 注入日志。
- 消减建议：丢包率监控；TCP 拥塞控制优化（BBR）；应用层重传/冗余；弱网降级；实时业务 FEC 前向纠错；丢包提示用户。

### NET-02d 网络包重复（Duplicate Packet）
- 典型原因：网络环路、路由错误、协议栈错误、重传机制异常；TCP 层处理异常。
- 典型影响：网络无法连接；网络接收错误、应用上网异常；TCP 序号错乱；应用数据重复。
- 故障注入：rphone 工具注入 `rNet fault=duplicate interface=netType ratio=10%`；netType（4G: rmnet0, WiFi: wlan0）。
- 日志/Trace：重复包统计；TCP 序号日志；应用数据重复日志；rphone 注入日志。
- 消减建议：TCP 序号去重；应用层幂等设计；网络环路检测；路由校验；重复包监控。

### NET-02e 网络包乱序（Packet Reorder）
- 典型原因：多路径路由、负载均衡、网络拥塞、不同链路延迟差异；TCP 层处理异常。
- 典型影响：网络无法连接；网络接收错误、应用上网异常；TCP 快速重传误判；应用数据乱序。
- 故障注入：rphone 工具注入 `rNet fault=reorder interface=netType time=1000ms ratio=30% coefficent=70%`；30% 包立即发送，其余延迟 1000ms，相关系数 70%。
- 日志/Trace：乱序统计（TCP out-of-order）；应用数据乱序日志；rphone 注入日志。
- 消减建议：TCP SACK 选择性确认；应用层序列号校验与排序；乱序缓冲区；网络路径一致性；乱序监控。

### NET-02f 网络服务中断（Service Down）
- 典型原因：网络断开、基站故障、WiFi 路由器故障、SIM 卡异常、APN 错误；网络服务进程挂死。
- 典型影响：网络无法连接、WiFi 无法自动连接；网络接收错误、应用无法上网；分布式业务中断。
- 故障注入：rphone 工具注入 `rNet fault=down interface=netType`；netType（4G: rmnet0, WiFi: wlan0）；关闭 WiFi/移动数据。
- 日志/Trace：网络断开日志（`link down`、`no carrier`）；WiFi 连接日志；移动数据日志；rphone 注入日志。
- 消减建议：网络状态监控与自动恢复；WiFi/4G 自动切换；网络服务进程保活；断网提示用户；离线模式支持。

### NET-02g 网卡带宽受限（Bandwidth Limit）
- 典型原因：运营商限速、WiFi 信道拥塞、QoS 策略、网络共享设备过多；下载限速。
- 典型影响：网络无法连接、上网速率慢；网络接收/应用上网延迟；大文件下载失败；视频卡顿。
- 故障注入：rphone 工具注入 `rNet fault=limit interface=netType downlimit=1024kbit uplimit=512kbit`；netType（4G: rmnet0, WiFi: wlan0）。
- 日志/Trace：带宽统计（吞吐量曲线）；限速日志；应用下载失败日志；rphone 注入日志。
- 消减建议：带宽自适应（码率/分辨率调整）；下载分片与多线程；限速提示用户；QoS 策略优化；带宽监控。

### NET-02h 网络闪断（Network Flapping）
- 典型原因：WiFi 信号弱、4G 基站切换、路由器不稳定、网线松动、IP 冲突；设备间连接中断。
- 典型影响：设备间连接中断；分布式业务异常；数据传输中断；频繁重连耗电。
- 故障注入：ip link set eth0 down/up 循环；route add/del reject 循环；WiFi 开关快速切换。
- 日志/Trace：网络状态变化日志（`link up/down`）；WiFi 连接/断开日志；路由变化日志；rphone 注入日志。
- 消减建议：网络状态防抖（hysteresis）；断线快速重连；连接状态监控；分布式业务断线恢复；闪断提示用户。

### NET-02i 下载大文件异常
- 典型原因：网络不稳定、存储空间不足、服务器故障、下载过程中断；涉及下载的业务需要构造大文件持续下载故障。
- 典型影响：下载失败、文件损坏、存储空间耗尽；业务中断；用户体验劣化。
- 故障注入：下载过程中断网；存储空间不足；服务器故障；构造大文件下载。
- 日志/Trace：下载失败日志（`download failed`、`insufficient storage`）；网络错误日志；存储日志；断点续传日志。
- 消减建议：断点续传；下载校验（MD5/SHA256）；存储空间预检查；下载失败重试；后台下载保活；下载进度保存。

## 二、通信稳定性（发现连接/传输/同步/组网）

## CS-01 发现连接（Discovery & Connection）

### CS-01a 主动发现
- 典型原因：首次发现连接；非首次发现连接；网络环境变化；设备状态变化。
- 典型影响：长时间主动发现成功率大于设计指标，无业务和系统故障。
- 故障注入：首次/非首次发现；网络变化；设备状态变化；长时间测试；观察成功率。
- 日志/Trace：发现日志；成功率统计；网络日志；设备状态日志；业务日志。
- 消减建议：发现超时保护；重试机制；成功率监控；网络状态检测；设备状态同步；长时间测试标准；业务异常检测。

### CS-01b 被动发现
- 典型原因：首次发现连接；非首次发现连接；广播/多播响应；设备状态变化。
- 典型影响：长时间被动发现成功率大于设计指标，无业务和系统故障。
- 故障注入：首次/非首次发现；广播/多播测试；设备状态变化；长时间测试；观察成功率。
- 日志/Trace：发现日志；成功率统计；广播/多播日志；设备状态日志；业务日志。
- 消减建议：广播/多播超时保护；响应限流；成功率监控；设备状态同步；长时间测试标准；业务异常检测。

### CS-01c 单一协议发现
- 典型原因：通过 BLE 发现；通过 COAP 发现；协议环境变化；干扰。
- 典型影响：长时间单一协议发现成功率大于设计指标，无业务和系统故障。
- 故障注入：BLE/COAP 发现；协议环境变化；干扰；长时间测试；观察成功率。
- 日志/Trace：协议发现日志；成功率统计；协议错误日志；环境日志；业务日志。
- 消减建议：协议超时保护；协议冗余；成功率监控；环境检测；干扰检测；长时间测试标准；业务异常检测。

### CS-01d 多设备混合协议发现
- 典型原因：多个设备发现包括 BLE 和 COAP 两种；协议切换；设备兼容性。
- 典型影响：长时间混合协议发现成功率大于设计指标，无业务和系统故障。
- 故障注入：BLE+COAP 混合发现；协议切换；设备兼容性测试；长时间测试；观察成功率。
- 日志/Trace：混合协议日志；成功率统计；协议切换日志；兼容性日志；业务日志。
- 消减建议：协议切换策略；协议超时保护；成功率监控；设备兼容性测试；长时间测试标准；业务异常检测。

### CS-01e 多设备发现
- 典型原因：典型组网；最大组网；设备数量变化；网络环境变化。
- 典型影响：长时间典型组网设备、最大组网设备发现成功率大于设计指标，无业务和系统故障。
- 故障注入：典型/最大组网；设备数量变化；网络变化；长时间测试；观察成功率。
- 日志/Trace：组网发现日志；成功率统计；设备数量日志；网络日志；业务日志。
- 消减建议：组网上限控制；发现超时保护；成功率监控；设备数量管理；网络状态检测；长时间测试标准；业务异常检测。

## CS-02 数据传输（Data Transfer）

### CS-02a 长时间双端操作
- 典型原因：长时间双端操作不间断触发数据传输；网络质量波动；设备状态变化。
- 典型影响：长时间双端操作触发数据同步/传输，数据传输无异常，无丢失数据。
- 故障注入：长时间双端操作；网络波动；设备状态变化；观察数据完整性。
- 日志/Trace：数据传输日志；双端操作日志；网络日志；数据完整性校验日志；错误日志。
- 消减建议：数据传输校验（CRC/MD5）；超时重传；数据完整性监控；网络状态检测；双端操作同步；长时间测试标准。

### CS-02b 反复本地和远端切换
- 典型原因：反复本地和远端切换触发数据传输；网络切换；设备状态变化。
- 典型影响：反复本地和远端切换触发数据同步/传输，数据传输无异常，无切换失败，切换时延增加等，无数据丢失。
- 故障注入：反复本地/远端切换；网络切换；观察数据传输。
- 日志/Trace：切换日志；数据传输日志；时延统计；数据完整性校验日志；错误日志。
- 消减建议：切换防抖；数据传输校验；时延监控；数据完整性监控；切换状态保存；异常恢复；长时间测试标准。

### CS-02c 反复对远端虚拟设备切换
- 典型原因：反复对远端虚拟设备切换；虚拟设备状态变化；网络变化。
- 典型影响：反复对远端虚拟设备切换，数据传输无异常，无切换失败，切换时延增加等，无数据丢失。
- 故障注入：反复虚拟设备切换；虚拟设备状态变化；网络变化；观察数据传输。

## DS-06 数据同步故障（Data Synchronization）

### DS-06c 同步过程中反复丢包
- 典型原因：同步过程中反复丢包；网络质量差；干扰；拥塞。

### DS-06d 系统高负载进行数据同步
- 典型原因：高 CPU、内存和 IO 负载下进行数据同步；资源竞争；同步优先级低。
