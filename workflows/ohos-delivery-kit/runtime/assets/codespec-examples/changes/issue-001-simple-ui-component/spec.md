## 用户故事或场景

### US-1: 导航按钮

**作为** 应用用户，**我想要** 点击导航按钮，**以便** 快速跳转到目标页面。

**验收标准：**
- **AC-1.1:** WHEN 用户点击导航按钮 THEN 跳转到指定的目标页面
- **AC-1.2:** WHEN 按钮处于禁用状态 THEN 点击无响应且视觉呈现禁用样式
