# Proposal

## 背景与问题

用户需要一个简单的按钮组件来触发导航操作。

## 初始分级判断

| 判断项 | 结果 | 依据 |
|--------|------|------|
| 复杂度 | 简单 | 单一组件，纯 UI |
| 涉及仓数量 | 1 | 仅 UI 仓库 |
| 是否涉及 Public/System API | 否 | 仅内部组件 |
| 是否涉及安全/性能关键路径 | 否 | 纯 UI 逻辑 |
| 是否跨 SIG | 否 | 单 SIG 内 |

## 目标

新增一个导航按钮组件，支持点击跳转到指定页面。

## 非目标

- 不涉及网络请求
- 不涉及数据持久化
- 不涉及权限申请

## 成功标准

| 标准 | 可观察指标 | 验证方式 |
|------|-----------|---------|
| 按钮正确显示 | 按钮可见且样式正确 | UI 验证 |
| 点击跳转正常 | 点击后跳转到目标页面 | 功能测试 |

## 影响范围

| 子系统 | 仓库 | 模块/路径 | 影响类型 |
|--------|------|-----------|---------|
| ArkUI | arkui | components/NavButton | 新增 |

## 假设与开放问题

### 假设
- 无特殊安全要求
- 无隐私数据

### 开放问题
- 无

## 不涉及项确认

| 维度 | 是否涉及 | 依据 |
|------|---------|------|
| 性能 | 否 | 纯 UI 组件 |
| 安全/权限 | 否 | 无敏感操作 |
| 兼容性 | 否 | 新增组件 |
| API/SDK | 否 | 内部组件 |
| IPC/跨进程 | 否 | 单进程内 |
| 构建/组件 | 否 | 无构建变更 |
| 国际化/无障碍 | 否 | 基础组件 |
| 数据迁移 | 否 | 无数据处理 |
