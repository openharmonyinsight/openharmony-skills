# ohos-delivery-kit workflow plugin

This directory is the neutral source for the `ohos-delivery-kit` plugin inside
the `openharmony-skills` workspace.

It keeps semantic components only:

- `skills/`: 24 ODK skills imported from the source repository.
- `prompts/session-router.md`: lightweight session router prompt.
- `hooks/session-router.yaml`: declarative session-start prompt injection.
- `runtime/assets/`: templates, profiles, contracts, rules, adapters, docs, and examples.
- `runtime/executables/validator/`: validator executable used by `odk-validate`.

Host-specific manifests, command wrappers, shell hook wrappers, OpenCode JS
wrappers, marketplace metadata, installers, and `dist/` outputs are intentionally
not maintained here. They should be generated by `ohos-agent build`.
